# 研究资产维护检查

这是 Finathink 改写的方法参考，不是已执行的研究或工具授权。输入、输出和资源以 L0 描述符为准。

## 使用方式

1. 检查受影响文件、源版本、许可、hash、字段合同和复现记录，区分源码变更与研究结论变更。
2. 检查测试、脱敏、安装包与恢复证据；保留真实 SAMPLE、阻断、错误和待验证标记。
3. 输出待办和验收清单，不因技能正文获得发布、删除、推送、重置、凭证或外部消息权限。
4. 实际工程变更由当前用户任务授权和项目流程执行；不继承上游账号、路径、版本规范或发布脚本。

## 交付

输出 MaintenanceChecklist，带授权证据引用、假设、缺口与下一步。没有计算产物时明确尚未执行；来源指标不写成本地结果。

## 资料

- [共用验证政策](../../policies/factor-validation.v1.json)，resource_id 为 factor-validation-v1。
- [适配与来源说明](references/context.md)，只在需要核对原始资料时继续读。
- 必需材料不足时列出缺口，不执行正文中的外部程序，不绕过现有授权、人工用途审核与 paper-only 边界。
