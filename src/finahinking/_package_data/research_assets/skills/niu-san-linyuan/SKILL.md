# 林园公开研究视角

这是 Finathink 改写的方法参考，不是已执行的研究或工具授权。输入、输出和资源以 L0 描述符为准。

## 使用方式

1. 以“质量、现金流与行业集中度”为研究问题域，先定位原始公开材料、披露时间、可用时间与身份确定度。来源汇编只是检索线索，不是人物事实或绩效认证。
2. 将观察、媒体归因、推断与反证分别登记；席位标签不等于个人身份，季报持仓不等于当前持仓。缺原文或身份不明时保留不确定性。
3. 把可观察行为改写成机制、字段、股票池、频率、标签窗口和反例条件，交给现有 FactorHypothesis/FactorProposal 合同与受控工具。
4. 依据共用政策检验披露对齐、样本选择、成本、同构与 OOS。输出证据卡和待验证假设，不作人物背书、跟随信号或有效因子声明。

## 交付

输出 BehaviorEvidence、FactorHypothesis，带授权证据引用、假设、缺口与下一步。没有计算产物时明确尚未执行；来源指标不写成本地结果。
