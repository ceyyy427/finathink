# 因子定义库与研究指南

因子定义库把来源、公式、数据要求和研究结果连接起来。打开本地应用的 `/research/factor-library`，按中文名称、字段、公式或家族筛选，再进入定义详情。

## 从定义到研究报告

1. 选择研究问题对应的因子，阅读公式、适用范围、单位、窗口和反例。
2. 展开固定版本的来源卡，核对项目提交、文件摘要和原式是否明确。
3. 准备自己的数据快照、面板合同及字段附件；合同声明股票池、时间范围、字段单位和复权口径，附件保留 `available_at`。
4. 在详情页填写研究问题，提交合同和附件引用。提交会固定公式版本、快照、面板与政策指纹。
5. 在因子实验历史查看后台任务、验证结果与报告。验证、候选冻结、保留集测试和审核沿用现有研究流程。

来源阅读和目录筛选是只读操作。只有显式提交研究才创建任务；计算结果保留对应的输入和版本，便于追溯。

## 十类研究问题

| 家族 | 可以研究的问题 | 典型输入 |
| --- | --- | --- |
| 趋势与动量 | 价格走势是否持续 | 复权价格、成交量、日历 |
| 反转 | 短期偏离是否回归 | 价格、历史窗口 |
| 波动与尾部 | 风险变化如何影响结果 | 收益、价格区间 |
| 流动性与换手 | 交易活跃度与冲击如何变化 | 成交额、成交量、流通股本 |
| 价值 | 价格相对基本面是否偏离 | 市值、盈利、净资产等公告数据 |
| 质量、盈利与应计 | 盈利质量和资金使用效率如何 | 财务公告、现金流、资产负债 |
| 成长与投资 | 经营增长与资本投入是否匹配 | 可比期间财务数据 |
| 行业与风格 | 信号来自个股还是共同暴露 | 时点分类、规模或行业数据 |
| 事件与机构行为 | 公告或汇总行为与后续变化是否相关 | 事件、发布时点、机构汇总数据 |
| ETF与宏观 | 基金状态与宏观条件如何关联 | 净值、持仓汇总、宏观发布和修订 |

具体字段与单位以每个定义的详情为准；数据由用户现有接口或文件提供。

## 如何理解目录数量与状态

来源卡与可执行公式分别统计。同一公式的窗口组合、别名和最外层方向变体归并统计，实验参数另行保留。来源卡标识原式明确或待解析，并保留来源证据状态；可执行项绑定独立版本、字段合同、数值样例和知识引用。

`RESEARCH_ONLY` 表示可用于研究。`READY` 表示当前输入可以完成定义计算；`NEEDS_DATA` 携带缺字段、单位、窗口或其他计算诊断。金融用途的审核范围单独记录，旧治理试点与历史引用继续按原版本解析。

## 时间、数值与可复现性

每个观察点只采用当时可见的数据版本。财务公告、宏观修订和ETF信息以可用时间选择，缺值保留原因。除零、对数定义域、样本不足与单位不一致需要检查原始输入或研究设计。

公式通过受控函数执行，记录时序或截面作用域。保留集与验证区间分离，冻结记录绑定候选及报告。报告中的数值样例用于核对计算口径；用户自己的市场、区间和成本需要对应的研究证据。
