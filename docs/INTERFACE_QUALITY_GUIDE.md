# 接口与研究质量指南

打开本地应用的「诊断与恢复」，进入「接口与研究质量」。页面沿用蓝白工作台，检查记录和研究任务都保存在当前本地空间。

## 先运行本地兼容检查

点击「运行本地兼容检查」。应用临时启动自己的本机 HTTP 服务，实际走数据连接器和模型兼容适配器，检查 34 个成功与故障响应：认证失败、权限拒绝、限流、坏 JSON、字段缺失、断流、流式响应、超时和响应大小上限。

下方三个合成评分示例继续走分析师、研究经理、引用校验与评分流程，共 14 次本机模型协议请求。整轮通常记录 48 次本地请求。这些请求全部由临时服务处理，没有使用用户接口或 API 额度。记录明确标记 `LOCAL_COMPATIBILITY`、合成样例及账号/TLS 未验证。

展开检查项可逐项核对预期和观察结果。下载 JSON、查看历史或刷新页面只读取记录，不重跑检查。

## 检查自己的接口

1. 先到「数据接口」或「模型接口」保存通用 API 配置和凭证引用。
2. 展开「检查我的已保存接口」，选择类型与配置。数据检查还需填写标的和 UTC 日期。
3. 核对授权说明并勾选，点击「检查一次」。
4. 从中文提示判断下一步：核对认证、权限、字段映射、JSON 响应设置或资源上限。先读取原记录，再决定是否准备下一次请求。

每次探测最多一次请求，数据最多一页，单次网络超时设置上限 5 秒。模型只接收固定的合成技术样例，输出上限 1024 单位。离线模式不会发送用户模型请求。诊断不下载完整市场历史、不创建研究快照，也不重试认证失败或限流响应。

请求标识在发送前保存在浏览器会话中，服务器在调用前持久登记。重复点击或响应丢失后使用同一标识读取原记录。进程重启不会自动重发；中断结果保留 UNKNOWN。浏览器无法保存标识时，用户接口和模型任务按钮会停用，本地兼容检查仍可运行。「准备下一次检查」明确创建一次新意图并清除授权。

## 用固定任务评估模型

选择自己的模型配置，以及下列样例之一：

| 样例 | 已冻结输入 | 重点观察 |
| --- | --- | --- |
| 材料齐全 | 合成日频 OHLCV、基本面、情绪、新闻与学习摘要 | 五类分析师及经理的结构、引用和分歧记录 |
| 材料不足 | 合成 OHLCV，其余四类材料缺失 | 四类角色应记录 INSUFFICIENT_DATA，不为缺失材料调用模型 |
| 观点分歧 | 合成 OHLCV 和包含冲突观点的摘要 | 保留研究经理实际记录的分歧，返回原报告复核 |

勾选本次模型调用授权后提交。任务使用现有 SQLite 队列、supervisor 和独立 spawn worker，最多 6 次模型调用、1 次任务尝试，总时长可设 5–300 秒，默认 120 秒。可以查看进度、取消、重新读取、打开原研究任务和下载质量记录。页面载入、切换历史、读取报告或进程重启均不会另建模型任务。

质量记录冻结样例版本、数据指纹、问题、材料、规则、工作流、角色模型映射与预算。后续修改模型配置不会重写历史评估。

## 读懂分数与未知值

| 指标 | 计数依据 |
| --- | --- |
| 结构接受率 | 已发出的调用中，被现有适配器接受的结果数 / 已发出调用数；失败保留在分母，结果未知时比例为 null |
| 输入引用归属 | 属于该角色、该运行冻结上下文的引用数 / 实际报告引用数；不是事实真伪或论证质量的自动判断 |
| 缺失材料识别 | 实际报告中正确标记 INSUFFICIENT_DATA 且无引用的缺失角色 / 预期缺失角色；报告不齐时比例未知，无预期缺失时无分母 |
| 用量 | 保留接口实际返回的中性单位计数；已知 0 与未知分开，缺少任一调用用量时不推算总量 |
| 耗时 | 各模型调用记录耗时之和；并行调用之和不是任务墙钟时长 |
| 费用 | 没有冻结单价与完整账单时为 null，不由模型名称推算 |

没有运行或发布校验失败时不提供成绩。已发生的失败、未发送、未知用量都留在记录中。固定样例展示工程与输入处理表现，不是投资收益或真实账号服务质量背书。

选择 2–4 个不同任务比较。相同样例、数据、规则、工作流和预算才标记「冻结条件一致」；模型供应商和角色模型映射作为比较变量展示。条件不同仍可并排阅读，页面不生成综合分数或收益排行榜。每条证据链接均指向自己的原始报告。

## 保存与恢复

接口详细记录每个空间保留最近最多 50 份，单份最多 128 KiB；已使用请求标识的摘要继续保留，详细记录过期也不触发重发。每个空间最多登记 10,000 个接口请求标识，达到容量时停止新增。质量任务使用原研究队列保存，页面一次显示最近 20 项。

本地 `artifacts/interface-diagnostics.sqlite3` 使用 0600 权限，记录只包含公开计数、状态和摘要，不包含凭证、接口地址、原始远程响应或完整研究上下文。研究质量导出含模型标识、已验证观察与报告链接，分享前请核对内容。

完整迁移沿用 [本地状态备份与恢复](QUICKSTART.md)：先结束任务并关闭应用，再备份并恢复到新目录。凭证值仍由用户自己的环境或系统凭证存储提供。

## 接口

所有 POST 沿用本地同源与 CSRF 保护。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/diagnostics/interfaces` | 读取接口检查历史 |
| GET | `/api/diagnostics/interfaces/<receipt_id>` | 读取/下载一份安全记录 |
| POST | `/api/diagnostics/interfaces/local` | 显式运行本地兼容检查，无参数 |
| POST | `/api/diagnostics/interfaces/probe` | 显式授权的单次用户接口检查 |
| GET | `/api/research/quality/cases` | 读取固定样例目录与版本 |
| GET / POST | `/api/research/quality/jobs` | 读取历史 / 提交固定样例任务 |
| GET | `/api/research/quality/jobs/<job_id>` | 从冻结输入、报告与调用账本读取评估 |
| POST | `/api/research/quality/compare` | 比较 2–4 个当前空间中的任务 |

测试与发布证据见 [Phase 18 验收记录](reviews/2026-10-31-finathink-phase18-review.md)。
