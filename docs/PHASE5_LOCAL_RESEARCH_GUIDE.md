# 本地研究闭环

Phase 5 对应产品完成路线的 Task 2–4：把用户数据快照、后台任务、确定性研究、进度、报告和重启连续性接通。模型材料与证据驱动的在线分析继续由 Phase 6 处理。

## 从页面开始

启动本地应用后，打开 `/research/jobs`，或从侧栏“研究任务”进入。

1. 在“配置自己的数据接口”保存连接、凭证引用和字段映射。保存操作只保存配置。
2. 在研究任务页选择连接、标的、起止日期及数据截止日，点击“获取并保存快照”。这是显式网络操作。也可以展开演示入口，生成明确标记为 `SAMPLE` 的快照。
3. 选择已保存的快照，填入标的、研究截止日、问题及墙钟预算，提交研究。
4. 查看阶段、尝试次数、失败位置、实际回测指标，或取消任务。
5. 完成后打开完整 HTML 报告。最近任务支持重新打开；已发布研究进入 Overview 和研究对比。

提交研究只传快照引用，不会再次从数据接口取数。刷新页面保留 `job_id`；服务重启后从同一数据库和 artifacts 目录恢复任务与报告。

## 输入与计算约定

价格字段为 `instrument`、`timestamp`、`open`、`high`、`low`、`close`、`volume`、`available_at`。本地低频基线要求同一标的每个 UTC 日期最多一条记录，至少四条。缺失的 OHLCV 不补造，可用时间缺失保持 `UNKNOWN`。

研究截止日采用 UTC 当日结束语义，观测时间和可用时间都必须在截止范围内。研究快照保留来源声明、连接引用、原数据指纹、质量问题，以及时区、复权和交易日历的声明状态；未知项保持未知。

本地默认运行配置为 `offline / local-deterministic`。五类分析师与经理走离线角色合同；研究问题作为假设留档。数值结果来自选定快照上的内部引擎：两观察期动量、阈值持仓、费用与滑点、历史风险检查、纸面组合及纸面成交模拟。周期是观测条数，不是日历天数；没有经过验证的交易日历时，年化收益、波动率、Sharpe 与 Sortino 保持未提供，保存结果重新评估也保持这个边界。

历史信号使用的数据必须不晚于下一根观测的执行时间可用；只在最终研究截止日前已知还不够。当前引擎无法证明因果性的迟发数据会停止量化验证，而不是生成带前视偏差的成绩。纸面目标仓位来自同一个策略的最新信号：无持仓信号时明确为全现金，风控也按该目标暴露检查。

报告展示数据指纹、引擎实际指标和适用限制，不把样本内基线写成 OOS 结论。数据模式与执行模式分开标记；`SAMPLE` 的合成数据警告、来源说明、质量问题与快照限制随分析 JSON、manifest、任务结果和可见 HTML 一起保留。

固定策略、费用和风险约束有独立的策略指纹。修改资源预算不会改变该策略指纹；旧任务遇到不一致的规则版本时停止，以新任务明确重新研究。

## 进程与发布边界

HTTP 服务启动时创建独立 supervisor，后者拥有 spawn worker。HTTP 请求只负责排队、读取与取消；构造 `LocalApplication` 或读取任务不会偷偷启动计算进程。

worker 从队列中的受校验请求引用恢复快照。每次尝试使用独立目录；结果收据绑定任务、运行、请求摘要、快照、尝试和租约。supervisor 复核收据、manifest、状态与文件摘要后，进行带租约围栏的队列完成操作；取消先发生时，产物不会进入正式研究库存。

正常完成由后台 owner 写入库存，不依赖浏览器轮询。若进程在“队列完成”和“入库”之间退出，下次启动或读取会复核收据并幂等补齐索引。缺失或损坏的报告保留历史条目，但停用报告链接；不会把别的报告代替原报告。

恢复采用确定性重放，使用原输入、剩余预算和独立尝试目录；不声称从内存中的回测循环中途续算。已完成任务不会为了重新查看而再次计算。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/research/snapshots` | 读取已校验的快照目录 |
| `POST /api/research/snapshots/capture` | 用已保存连接显式获取并冻结快照 |
| `POST /api/research/snapshots/sample` | 显式生成演示快照 |
| `POST /api/research/jobs` | 提交引用式研究请求，返回 202 |
| `GET /api/research/jobs` | 分页读取当前会话的后台任务 |
| `GET /api/research/jobs/{id}` | 读取进度、失败位置、指标及报告入口 |
| `POST /api/research/jobs/{id}/cancel` | 请求取消，终态保持幂等 |
| `GET /api/research/runs` | 筛选、排序及分页读取已发布研究 |

写请求需要页面中的 `_csrf`。提交字段为 `idempotency_key`、`snapshot_ref`、`instrument`、`as_of`、`question`、`model_config_ref` 和可选 `budget`。凭证、用户路径、原始数据、任意导入路径或执行代码均不是提交字段。

任务与研究库存按本地会话作用域读取。它是本地单用户隔离边界，不等同于互联网多租户认证系统。数据凭证在显式抓取时由连接层解析，不交给本地研究 worker。

## 资源与留存

默认预算为 120 秒、2 次尝试、2 次实验、10 MiB 已计量字节、最多 2 个并行 worker；离线流程实际模型调用次数为 0。允许请求更小预算，或在服务端上限内调整预算。截止时间随任务持久化，重试不会刷新截止时间。

字节计量覆盖快照输入及实际生成的报告文件，在正式发布前检查。它不是操作系统磁盘配额；被取消或预算阻止发布的尝试目录保留为私有诊断产物。崩溃前尚未回传的资源计量不能精确还原，墙钟与尝试上限仍保持持久化约束。

浏览器每秒读取一次当前任务，最多自动读取 300 次；终态、页面离开和任务切换都会停止旧的观察。自动观察暂停不等于取消后台任务，可以点击“重新读取记录”继续查看。

## 验收证据

测试覆盖两份不同数据的实际因子与回测差异、数据与策略指纹、快照篡改、未知 PIT、历史可用时间、全现金信号一致性、未知日历的年化抑制、合成数据警告、幂等提交、并行隔离、运行中取消、owner 崩溃恢复、输入与报告预算、无客户端轮询的自动入库、页面与服务重启连续性，以及报告文件损坏。

浏览器用真实本地 HTTP 服务和真实 spawn 引擎走完整流程，并检查 1440×900、1920×1080、375 像素宽度、键盘焦点、空态与错误恢复。CI 的浏览器门禁纳入这些旅程，上传截图、页面、诊断与 JUnit；中文字体由 CI 系统包提供。

已有 `/research` 示例图表保留原入口；真实引用式提交入口是 `/research/jobs`。两者明确区分，避免把示例数据误当作用户选中的输入。

本地最终验证：1123 项 Python 测试通过、1 项可选适配器跳过；前端单测 29 项通过。独立审查发现的历史可用时间、仓位一致性、年化语义和数据来源披露问题，以及托管 CI 暴露的队列连接生命周期、仅安装 headless shell 时的浏览器启动预检问题，均已通过失败复现与回归修复。可选 statsmodels 适配器另由托管量化 CI 验证。
