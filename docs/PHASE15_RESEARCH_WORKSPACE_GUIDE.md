# 方法、因子与离线报告指南

Finathink 将资料、冻结方法、类型化提案、数据、实际计算和用途审核串入同一本地工作台。蓝白外壳沿用用户指定的 HTML，研究状态由服务器事实生成。

## 一条可复查的流程

1. 打开 `/library/methods` 检索方法；公开行为与反例分别在 `/library/behavior`、`/library/lessons`。展开查看来源、版本、必需输入与资料缺口。浏览资料只读，不代表已经执行。
2. 点击“带入研究问题”，进入既有 `/research/jobs`；选择已保存的数据快照和标的，核对日期、问题、模型配置与资源预算后提交。
3. 选定任务后，在“方法交接与受控因子研究”显式导出因子研究包。外部研究工具读取包中的冻结方法与证据，按 `method-result.v1` 返回绑定原包的 JSON。这里不是自动调用当前 Codex 会话的驱动。
4. 粘贴回传并校验，选择已保存的类型化产物。需要额外字段时，上传 `ResearchFieldAttachment` JSON：指纹绑定同一快照，逐条声明可用时间，单位按合同填写。不是上传 Python 或任意代码。
5. 显式建立受控研究。跳转 `/research/experiments?study_id=…` 查看真实九步轨道、验证候选、冻结与最终测试；缺字段、费用或容量条件不满足时保留具体阻断与 `NOT_RUN`。
6. 因子详情 `/research/factors/{factor_id}` 分来源、定义、公式、数据、验证、用途与反例七区。可用 `version`、`window`、`run_ref` 指定历史证据，旧定义不可解析会如实显示，不替换成今天的实现。
7. 计算与研究批准分开。用途审核绑定原公式、市场、股票池、时间域、用途、政策与评估。观察刷新仅生成复核提案；学习预览、显式审核与版本复跑沿用原复盘工作区。

方法、行为档案与反例只描述研究协议。人物行为资料需要用户提供可核验的公开材料，不能推断真实持仓或收益。受控原式可运行不等于上游实验成绩已在本地复现。

## 自包含报告

新报告使用 `blue-white.v1` 主题。因子报告包括冻结的方法清单、公式版本、快照与附件、政策及验证指纹、九步原始状态、来源对照、实际净值和同源表格。没有实际回测时不给空白状态补收益曲线；原生折叠和目录不依赖 JavaScript。

`manifest.json` 保留方法/数据/政策/验证摘要和文件哈希。公开报告只保留方法清单，不复制私有方法包的完整正文；方法正文在脱敏前校验原哈希，公开脱敏不能伪装成原文未变。

报告打开时不请求 CDN、模型或本地 API。旧报告读取、重启、备份恢复均返回原字节；模板更换不改写原文件。相同运行重放返回原 manifest，改变输入需要新运行编号；发现损坏时应恢复原备份，不覆盖原记录。

## 操作与恢复

- 搜索为空时清空条件；读取失败可保留条件与原列表重试。搜索与资料页不生成任务或触发模型。
- 键盘可访问搜索、原生折叠、表格和目录；移动导航遵循原外壳的焦点与 Escape 行为，支持减少动态效果。
- 方法回传保留草稿。切换任务后引用会重置，必须重新导出和绑定，避免将旧包的结果写入另一任务。
- 备份包含本地研究队列、方法包、附件、章程与报告，恢复到新目录后可继续读取。私密备份不是可公开分享文件。

实际用户数据服务与付费模型调用的验收须使用用户自己的账户和明确授权，工程 fixture 与受控 JSON 回传不替代这项验收。通用数据 API 是产品接入边界，不维护具体数据供应商 SDK。
