# 中文试用与反馈指南

本轮交付围绕三件事：第一次安装后能生成报告；数据和模型调用由用户明确发起；异常后能找回记录、导出诊断并恢复状态。

## 当前验收范围

| 范围 | 证据与边界 |
| --- | --- |
| 新安装与首份报告 | 全新独立虚拟环境从 wheel 导入，真实本地 HTTP、Supervisor/spawn worker、离线报告、私密备份恢复与重复启动。 |
| 中文关键旅程 | 导航、研究任务引导、问题模板、数据接口表单、异常提示与诊断入口；保留已有深色视觉系统。 |
| 数据配置旅程 | 浏览器填入接口与测试凭证，保存不读取数据；用户显式获取快照后进入真实 worker。远端与凭证存储为受控测试替身，不代表真实账户授权。 |
| 稳定性与访问 | 1440×900、1920×1080、375×812；键盘焦点与操作、ARIA 可访问树、加载/空/错误/恢复、损坏报告、25 项历史的 20 项分页。 |
| 性能 | Chromium 4 倍 CPU 限速旅程与实际耗时日志；另有 10,000 行图表数据解析基准。这是模拟限速，不是实际低端硬件验收。 |
| 待用户试用 | 真实服务凭证、macOS 系统凭证存储授权、外部网络质量、真实屏幕阅读器与设备组合，以及人类参与者反馈。当前为 `NOT_RUN / EXTERNAL_UNVERIFIED`。 |

研究问题模板不切换数值策略；多代理观察不会直接改动数值权重。学习提案仍需显式审核，新版本复跑保留旧报告。所有研究保持纸面、描述性与可追溯口径。

## 一次试用怎么进行

按 [快速开始](QUICKSTART.md) 操作，逐项自行记录，不预填“通过”：

- [ ] 在新的本地目录安装并启动，打开“研究任务”，能理解下一步。
- [ ] 未配置任何 Key 时，显式生成 SAMPLE 快照并得到第一份报告。
- [ ] 保存 HTML 文件，离线打开；重启应用仍能找到同一个研究。
- [ ] 可用键盘选择模板、提交研究、打开报告与翻页，能看清当前焦点。
- [ ] 如有自有数据 API，保存接口后确认尚未读取，再明确获取快照、核对用户数据标记与指纹。
- [ ] 如有模型服务，在理解发送范围和费用后选择接口并授权；资料不足、调用失败和未知用量都能辨认。
- [ ] 出错时，知道先重新读取原任务，再决定是否新建；可下载脱敏诊断。
- [ ] 所有任务结束且应用关闭后备份，恢复到新目录，核对原报告仍在。

真实 API 调用可能消耗用户自己的额度。私密备份包含数据与研究材料，不用它替代脱敏诊断。请保留原安装与备份，恢复操作不覆盖已有目录。

## 试用状态

本次提供可重复的内部验收与试用材料，没有创建外部账户、发出邀请、进行真实付费调用或收集人类参与者反馈。维护者安排小范围试用后，再逐项补充真实环境证据；自动化测试结果不替代这些记录。
