# Phase 19：研究差异、复现与量化证据

用户已授权沿路线图实现、测试、审查、修复并合并发布，无需中途确认。以下实现取舍由执行者负责。

## 目标与边界
在现有本地研究流程中解释数据、方法、参数、费用、风险政策、代码/依赖六类差异；将可移植、脱敏的研究输入与确定性产物一起导出；恢复后明确区分匹配、差异和缺依赖。补充多资产的单位/PIT、因子暴露、风险归因、压力敏感度及不确定性证据，并在同一对比工作区阅读。

继续 Python >=3.11、现有 numpy/pandas、原生 JS、蓝白 AppShell。无新增运行时依赖。用户提供数据；不接供应商 SDK；所有计算本地、纸面研究。未知值不得变成零，来源主张不得成为本地计算结论。旧报告缺身份时显示未知，不追溯伪造身份。

## 方案与选择
仅扩展原有条件分组无法解释不兼容或迁移。另建研究引擎会产生双重事实源。因此选择：在原工作流冻结执行身份；新服务只投影已验证报告，调用原确定性内核复算；新 UI 接入原对比页。

执行身份包含声明的算法版本、参数与风险政策，以及 Python 源码内容摘要和 Python/numpy/pandas 版本清单（不导出路径）。身份写入报告后不根据当前配置回填。

六类差异逐字段显示 SAME / CHANGED / UNKNOWN。完整相同的前提下允许指标差值；缺失身份或不兼容禁止合并排名。两边均缺字段也是 UNKNOWN。

## 迁移与恢复
使用有大小上限、版本、内容摘要、严格字段白名单的 JSON 研究包；不使用可执行内容、pickle 或任意文件路径。导出默认只包含元数据和缺依赖清单；用户显式选择才携带标准化数值数据。连接配置、凭证、端点、提示词、私人材料和原始来源文本均不导出。保留数据模式，SAMPLE 不能改称真实市场。

每个产物单独声明复现覆盖：原基线回测、路径归因、风险输出和多资产量化证据可本地复算；原模型文字仅作原报告引用，不重新调用模型。受冻结测试控制的因子研究继续通过原研究流程，迁移包列出因子方法、字段和冻结授权依赖，不将基线复算成功冒充整份报告复现成功。验证阶段导出只包含已发表前缀，禁止带出隐藏测试数据。

脱敏后的数据摘要与原摘要分别保留；复算比较数值产物，不声称运行 ID、原数据出处摘要、生成时间或 HTML 字节相同。输入、代码或依赖不匹配返回明确阻塞，绝不安装研究包指定的代码或自动访问网络。恢复保存到内容寻址的本地独立存储，重复导入幂等；不改变原任务、因子准入或风控政策。缺依赖保留清单，可重新导出带数据包。

## 多资产证据
在原数据快照上新增只读 evidence section。每个资产需明确价格/现金货币、volume=shares、资产类型 EQUITY/ETF 与历史 availability；同币种才聚合，不猜 FX。限制最多20资产、总计20000条记录，复算包最多5000条。各资产先按自己的相邻观测算收益，再按同一对起止时间交集对齐，不前向填充、不把跨缺口收益混成日收益。缺单位/PIT或覆盖不足逐项阻塞证据，不改变既有单标的回测。

组合证据采用明确的等权固定研究权重，区别于实际决策持仓。计算行业/动量暴露、样本协方差 Euler 方差贡献（允许负贡献、总和等于组合方差）、经验 CVaR；压力按声明的市场/行业/动量情景生成。敏感度为已测冲击网格，稳定点表示未超声明损失上限，不能解释为未测试连续区间。均值不确定性使用固定种子、移动区块 bootstrap（200次、95%区间、至少20共同收益）；同时显示样本数、共同覆盖、区块长度、方法和限制，不提供获利概率或虚构置信评分。来源主张单独标为未验证；合成样例只验证计算。

## 产品与验证
对比页新增运行选择、六类差异表、量化证据列、导出/导入/复算及缺依赖阅读。保留服务器渲染内容、键盘和可见焦点、减少动画、移动无溢出。GET 不启动计算/调用；所有变更 POST 经过现有 CSRF。错误中文、重复点击合并、迟到响应不覆盖当前选择。测试包含手算多资产与负贡献、缺单位/非同步/未来数据、实际 spawn 报告、重启/新目录迁移、内容篡改和跨 scope、真实 HTTP/浏览器、安装包旅程。最后全套测试、独立审查、PR 与合并 main CI 验证。
