# Phase 18：接口诊断与分析师质量评估

依据：已发布 Phase 17（main `4c3dffc`），接续 `FINATHINK_NEXT_IMPROVEMENTS_2026-10-27.md` 的 Phase 18 两项。用户已授权按计划自主实施、修正、测试、审查和发布，沿用 Native 执行。

## 目标与选择

让用户分清接口连通、返回结构、证据绑定和研究解释质量。复用通用数据连接、兼容模型适配器、既有研究队列/worker/预算/调用账本，在蓝白“诊断与恢复”中提供操作入口。

选择服务端持久诊断记录、本地 HTTP 兼容验收与固定样例研究评估。单做表单错误文案无法复现问题；另建模型执行器会重复预算、恢复和授权流程，因此实际模型评估仍进入现有研究任务。实现细节由本轮确定，界面沿用现有 DESIGN.md，不改变视觉方向。

## 1. 有界失败合同

数据诊断只取一页、一次 HTTP 尝试，请求超时 5 秒；研究数据入口继续使用原默认分页/重试合同。保留可辨认的鉴权、权限、限流、非 JSON、缺字段、结构错误、超时、响应过大、传输中断和不支持的 SSE 状态。返回失败时不得泄漏响应体、地址、凭证、路径或异常堆栈。

模型仍用非流式 JSON 请求。不把半截 Content-Length/chunked 消息当完整 JSON，也不把 SSE 冒充已支持的模型流。新增类型化传输错误由适配器、契约检测和调用账本共同识别。生产 HTTPS、DNS 公网校验、地址固定、禁止重定向及字节上限保持有效。

## 2. 诊断与证据

新增 scope 隔离、0600 本地 SQLite 诊断库。保存受控公共投影，每 scope 最多 50 份，每份至多 128KiB；包含版本、来源类别、预期/实际状态、请求次数、时间、用量、缺字段和修复动作。省略地址、配置全文、原始材料/响应、Key/引用名称及用户数据行。下载只读，刷新和恢复不发出请求；损坏记录显示不可用。

外部探测使用已保存连接/模型配置，必须逐次勾选授权；数据按用户提供的标的读取一次，模型只发送固定合成技术材料、最多一次调用和 1024 输出单位上限。离线模式拒绝模型外发。凭证缺失不发送请求。金额没有可靠账单时为未知；已出站未得到用量也保留未知。

外部探测先持久化幂等预留再执行。同键同输入只返回原记录，不重复调用；同键不同输入拒绝。中断预留保持不确定状态，不能自动重发。每条记录均可定位修复入口（数据/模型设置、研究输入或诊断说明）。

## 3. 本地兼容验收

显式操作启动仅绑定 127.0.0.1 的临时标准库 HTTP 服务，用真实字节传输经过现有 JSON 连接器与两个兼容适配器。私有注入连接仅用于这个固定合成服务，不能由 API 指定地址或变成生产私网通道。覆盖成功、401、403、429、坏 JSON、缺字段/错误结构、截断传输、SSE、超时；结果按预期与观察逐项判定。

报告始终标记 LOCAL_COMPATIBILITY / SYNTHETIC、未验证 TLS/真实账号。本地通过证明工程合同，不能提升任何保存的用户接口为已验证。页面加载、保存设置、导出和重启都不运行验收。无新增供应商 SDK 或运行依赖。

## 4. 固定质量任务与真实研究记录

提供三个版本化合成任务：材料齐全、材料不足、观点分歧。目录公开问题、数据/材料摘要、可用时间、预期角色资料状态和评分口径。显式创建样例研究时保存 SAMPLE 快照，用户选择已配置模型并重新授权；通过既有 ResearchApplicationService.submit 进入 supervisor/spawn。每项最多六次模型调用、一次尝试，墙钟预算使用既有 5–300 秒约束（页面默认120秒）。默认本地兼容验收可以演示评分，真实模型评估不自动运行。

持久保存样例版本/输入指纹/任务绑定；同一幂等标识不重复入队。只接受库内任务、既有用户模型配置和明确预算，不接受任意提示词、地址或模型代码。记录损坏、快照/材料/任务绑定不符时不评分。

评估从真实任务和调用账本读取：结构接受的已出站尝试、引用成员有效率、缺材料时正确保留资料不足的角色、经理记录的分歧、模型调用时延和用量。失败调用纳入分母；未发送不当失败；中断或未知不能按零计算；没有观察时指标为 null，分母和缺口单列。引用有效仅指属于这轮上下文，不证明语义或金融结论正确。排队、离线或发布损坏分别保留状态，不伪造成功评分。

比较最多四项研究，只有任务版本、数据/材料/问题、政策、工作流与预算一致时可直接比较；模型供应商/角色映射是可变项并明确列出。同名任务不代替指纹校验，不把合成评估当市场表现排名。保留每个角色与经理的证据链接和分歧，绝不写因子权重、风险政策或真实订单。

## 5. 界面与交付

诊断页分为“本地兼容验收”“检查自己的接口”“模型研究评估”“已保存证据”，先展示结果与下一步，技术详情使用原生 details。所有执行按钮显式触发；采用既有 CSRF、中文错误、加载/空/失败/恢复状态、可见焦点、减少动态效果、无脚本的记录阅读与 JSON 下载。设置页增加就近入口；保存配置不产生探测。

验收：先失败后实现；真实 HTTP 的正常及异常字节、密钥不出投影、并发幂等/中断、跨 scope、未知用量/零值、错误引用/缺材料、不同任务不可比。实际 spawn 通过受控测试 peer 验证固定任务→报告→评估→重启。1440/1920/375 截图与键盘、网络错误恢复；wheel/备份恢复、Node、完整 Python、Ruff/governance/secret/依赖/构建和 CI。一次独立整分支审查后修正，PR 检查全通过再合并并检查 main。
