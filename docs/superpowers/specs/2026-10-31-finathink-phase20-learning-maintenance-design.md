# Phase 20：可靠复盘与本地任务维护

用户已授权按路线自主实现、测试、修复、审查并合并发布。本阶段复用现有学习审核、版本政策、队列、独立 worker 和蓝白界面，不引入运行时依赖或供应商 SDK。

## 意图与实现选择

单次亏损目前即可产生 10% 收缩预览，缺少跨样本依据；任务列表逐项加载完整报告，轮询会重复校验。只增加文案不足以证明建议可靠性，另建学习/任务引擎会分裂事实源。因此由执行者选择：新增冻结的样本评估与成对复跑，继续交给既有审核/worker；任务侧新增轻量分页和可失效的短时校验缓存，以公开本机基准验证优化。

原单次复盘保留为明确标注的探索性试验，批准时必须单独确认探索属性；它不属于可靠建议。历史已批准版本继续有效。只有下面的样本评估可以生成基于样本的建议。开发过程无需用户干预；产品中的配置审核仍由使用者显式完成。

## 可靠学习证据

从一项已结算普通纸面复盘派生范围：父政策、标的、source/evidence/observed 数据模式、冻结执行身份、固定五观察期及执行成本规则。用户明确起始日与截止日，服务自动收集当前 scope 内全部候选记录，不接受挑选赢家/输家的 ID 列表。

最多读取 200 个候选，超量要求缩小范围，不悄悄截断。记录必须已被观察、在截止时刻可用，且有可校验的原报告、原数据和后续快照。重建纸面结算并核对原事件与记录；未知、篡改、跨配置/模式/代码、回溯复跑、未成交或未来记录逐项排除并说明。按时间稳定排序，去重经济信号与结算身份，只选相互不重叠的决策至估值/可用时刻窗口；这表示操作上的样本分离，不保证金融序列统计独立。

经济信号身份不随请求截止日或后续结算窗口变化。候选证明无法完整校验时，保留其余样本的描述统计并暂停生成建议，避免缺失反例强化建议；生成建议入口再次检查该限制。

固定工程门槛：至少 20 个合格窗口，净收益均值小于零，亏损比例的双侧 95% Wilson 区间下界大于 0.5，才建议现有预算/风险上限各收缩 10%，沿用预算下限 0.1 和 CVaR 下限 0.01。否则保留配置或继续观察。门槛不可在请求里调参，不能解释为真实市场校准或未来盈利概率。显示样本数、覆盖期、排除原因、收益分布、全部亏损/非亏损数量、最多 20 个反例及区间假设；零和未知分开。

评估按内容摘要持久化，绑定样本证明与父政策；重复相同评估幂等。显式生成建议前重验冻结证据。建议通过 LearningReviewStore 的原预览、审核和版本创建流程，没有自动调权。无数值变化不创建空版本。普通单次试验审批新增 allow_exploratory=true，记录审核者模式；旧已批准文件可读，未批准旧提案同样需要确认。

## 冻结成对复跑

从已批准复盘创建一次“父版本 vs 已批准版本”，两边使用完全相同的快照、标的、截止日和当前代码，仅政策不同，均走现有离线 worker。先持久化绑定，再用确定性幂等键分别排队；重启/半完成可通过显式继续补齐，GET 不创建任务。最多两个正常受预算约束的任务，无模型外发授权。

两边报告均校验通过、输入与冻结身份匹配时才计算有限数值差值。失败、缺产物、代码变化或身份失配分别显示，不能把部分完成当成成对成功。复用学习期或政策生效前数据标为回溯；较晚窗口也仅是描述性成对研究，不自动变成新学习证据，不覆盖原报告。原始/新版本、证据来源、配置差异和运行链接都可追溯。

## 本地维护与性能

新增 scoped 轻量任务列表：每页 1–100，基于创建时间/ID 的游标，冻结初始 SQLite rowid 水位，新增任务不挤动已有翻页。返回元数据和明确的未校验报告状态；打开详情仍执行原完整校验。跨 scope、非法游标、重复/遗漏和重启有回归。原 offset API 保留兼容。

完整报告采用进程内、有界 64 项、2 秒 TTL 的成功校验缓存。每次命中仍检查路径、符号链接以及清单/文件的设备、inode、大小、mtime_ns、ctime_ns；变化即重新校验，失败不缓存。线程安全；不缓存模型响应/任务写入，不持久化缓存，不承诺抵御能伪造文件系统元数据的敌对管理员。

维护视图只读：当前 scope 的队列状态、到期/退避/取消情况、最近最多 100 项任务的实际阶段耗时、重试与资源消耗，以及本地数据库/WAL 大小、磁盘余量和缓存命中计数。未知为未知；进程指标明确属于本地应用，不冒称 worker 全机资源。GET 不恢复租约或启动研究。恢复/取消继续走既有显式操作。

公开基准脚本默认 1000 个 SAMPLE 队列任务、20 次读测量、并发与实际两任务 spawn、完成后重开、可控租约恢复。先记录原列表/冷校验，再测轻列表/暖缓存及失效；输出 Python/SQLite/平台、样本规格、重复次数和实际时间。没有测得的提升不写成收益，不把本机值当所有设备保证。
