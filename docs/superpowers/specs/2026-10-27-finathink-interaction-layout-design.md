# Finathink 交互与布局细化设计

日期：2026-10-27。依据：用户要求增加淡入等交互感、使布局适中，并整理 UI 之外的改进点；沿用此前授权的自主实施、测试和审查方式。

## 意图与范围

在现有蓝白研究工作台上，让进入页面、打开搜索、展开资料、按下操作的反馈更连贯。用户应该立即看见内容、继续输入与检查证据，动效不能成为等待流程。本轮是既有外壳的细化，不更换视觉风格或研究事实源。

本轮交付共用布局与反馈、浏览器回归、验证记录和后续能力路线。其他能力按建议排序，本轮不同时改写后端研究系统。

## 方案选择

1. **原生 CSS，采用。** 外壳已是服务端 HTML 与渐进增强脚本。短淡入、按钮反馈和原生 dialog 的打开动画都可由 CSS 表达，不增加运行依赖，也不改变数据流。
2. **引入动画框架。** 适合复杂手势或跨节点编排，当前成本大于收益；以后出现真实空间关系需求再评估。

以下具体尺寸和时间是本轮实施选择，而非用户指定常量。

## 空间关系

- 主要路径仍为问题 → 数据与方法 → 研究 → 证据、比较和复盘；保留 224px 导航、292px 上下文和现有移动抽屉。
- 工作区最大宽度由 1740px 收到 1480px，居中；桌面水平留白为 32px，宽屏 40px，紧凑桌面 24px，移动 18px。列间距使用 24px，紧凑桌面保持 18px。
- 顶栏的内容与工作区边缘对齐，背景仍跨满主框架；页脚使用同一内容宽度。宽表格在自身容器滚动。
- 正文和说明保持现有阅读宽度；内容卡不添加悬浮位移或整卡点击语义。

## 动效与反馈

- **到达：** 工作区一次 180ms 的轻淡入，初始不透明度为 .72，无位移、延迟或滚动触发。导航、顶栏保持稳定；轮询结果不会重播整个页面动画。
- **受保护的搜索：** dialog 打开时 200ms 淡入与 6px 上移，遮罩仅淡入 150ms；关闭即时，Escape 与焦点恢复维持原逻辑。
- **明确展开：** 原生 details 的直接内容在打开时 140ms 淡入，不改变 summary、文档顺序或可访问名称。
- **操作确认：** 交互控件的背景、边线、文字在 120ms 内过渡；启用状态按钮按下时轻微缩小。禁用按钮不发生位移，普通信息卡不假装可点击。
- **减少动态效果：** 关闭页面、弹窗、展开和按压位移；保留至多 100ms 的颜色反馈与可见状态文字。运行中切换系统偏好也应立即生效。
- **预算：** 仅使用有界的 opacity/transform 动画，无滚动观察器、无限循环、布局尺寸动画、默认隐藏或持久 will-change；打印不带动效。

## 验证边界

在真实 HTTP 工作台验证 1440×900、1920×1080、2560×1440、1024×900、390×844 和 375×812；验证搜索、键盘焦点、快速开关、减少动态效果、无 JS 与数据/任务零额外提交。观察完成后的截图另存，不将动画中的半透明截图当作最终效果。

检查原有浏览器交互、前端测试、构建、性能检查和 Python 全量；由独立审查覆盖变更范围。离线旧报告的字节与指纹保持原约束，新动效仅作用于应用外壳。

参考：[MDN 减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)、[web.dev 动画性能](https://web.dev/articles/animations-guide)。
