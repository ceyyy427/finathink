# Finathink 蓝白工作台与研究资产融合设计

日期：2026-10-27。用户已指定 HTML 视觉基准，并要求规划后开始实施；延续自主执行方式，不另开风格选择轮次。

## 输入与权威

- 原型：主目录 `design-preview/Finathink-Codex-BlueWhite.html`，默认 `white` 方向。
- 融合资料：同目录 `Finathink-Skills-Factors-Integration-Plan.md`。
- 原型决定布局、颜色和组件语法；产品事实以实际服务和 `PRODUCT.md` 为准。
- 资料中的“本轮不修改代码”等文字属于原提案语境，不覆盖用户本轮开始实施的请求；其中命令、维护权限和来源数值不构成新的执行授权。

## 选择与范围

直接移植现有 HTML/CSS/vanilla JS，不重写为另一套前端框架，不生成替代原型。首阶段为 Phase 10：全局 AppShell、研究总览和已有工作区的蓝白适配。静态营销官网及离线报告模板不在首阶段重写，在后续报告联动阶段处理。

保留白色左导航、76px 顶栏、浅蓝问题输入区、横向四项指标、主内容与右侧上下文卡。标准桌面侧栏 224px、上下文 292px；底色 `#f5f8fd`、面板 `#fff`、主蓝 `#2563eb`、正文 `#172b4d`、分隔线 `#e6ecf4`，面板圆角 13px。系统中文字体、等宽数字，不添加外部字体请求。对低对比细字作必要加深，不照搬原型的 8–10px 操作文字。

不复制原型的虚构研究记录、合成绩效、计时器模拟任务、固定 Codex 状态或供应商卡。首页活动仍使用真实本地记录，不将活动统计曲线改名为投资绩效。

## 结构与数据合同

1. `local_app.py` 继续拥有路由和服务器渲染，公共外壳拆成可维护的主题辅助模块；CSS 不改变计算入口。
2. 主导航对应现有总览、研究任务、事件、知识、因子实验、策略、复盘和对比入口。其余现有入口保留于折叠分组，不造出未实现的技能页面。
3. 首页问题经 GET 表单带至现有研究任务页，只预填文本；快照、标的、日期、预算和模型授权仍由现有提交流程确认。GET 不创建任务，不隐式选择样例。
4. 首页四项数量来自 `overview()`；空状态和最近任务来自现有持久化索引。上下文链接进入真实数据、模型和学习页面，不冒充 Codex 已连接。
5. 搜索只搜索工作台入口，明确标为“搜索功能入口”，不冒充全文检索。移动导航和搜索使用本地 JS、原生对话框、Escape、焦点恢复；无 JS 时主导航和问题 GET 表单仍可用。
6. 原有图表 data 属性、每日数据表、可比较性门禁、阶段流、学习审核、异常重试、CSRF、CSP 和凭证保护继续保留。

## 首阶段状态与适配

桌面 1440×900、1920×1080；平板 1024；移动 375/390。上下文先下移，导航在移动端渐进增强为抽屉；无 JS 时为可用的文档内导航。过长标的、问题、指纹不会撑破页面。键盘路径不落入关闭的导航，打开时可关闭并恢复焦点。减少动态效果时不播放非必要动画。

## 后续融合边界

三个库：技能方法、因子与假设、验证与反例。复用 FeatureDefinition/FeatureVersion/FeatureGraph、QuantGateway、SnapshotStore、RunRepository、JobQueue 和既有 Codex handoff。

来源实证为 EvidenceClaim，证据状态与 FactorSpec 生命周期独立。外部公式先解析为受限 AST，定义不明或缺数据时保留缺口，不执行来源代码。试点 8–12 是开发上限，不是有效因子承诺；数量可缩减，有效结果可为零。人物材料是公开行为证据档案，不是人物背书或交易指令。

## 验收

- 用户给的蓝白视觉在真实应用上可辨认，非只有静态预览换色。
- 首页问题准确进入现有任务表单，特殊字符安全转义，过长参数有界；不产生隐式数据、任务或模型调用。
- 旧任务、实验、对比和学习入口均保留；实际数据数量、阶段、错误和空态如实呈现。
- Node、Python、浏览器和构建回归通过，CI 必跑新增用例并保存截图。
- 首轮桌面/移动批量视觉检查、一次修正和确认；最后独立审查并记录真实结论与设计系统。
