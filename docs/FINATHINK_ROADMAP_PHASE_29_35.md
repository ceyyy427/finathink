## 阶段 29 · 用户数据到可研究面板

**交付**　用界面选择已保存的数据连接、快照、资产、日历和字段附件。按因子或策略列出所需字段、单位、可用时间和覆盖率，可预览、保存并复用有指纹的面板。接通因子、策略和研究发现三个入口。数据来源和使用权限由用户管理。

**验收**

- 用受控 HTTP 验证认证、分页、增量、限流与重启重读。用股票、ETF、财务发布时滞三个样例完成「配置 → 抓取 → 映射 → 面板 → 后台报告」。
- 缺字段、错误单位、迟到数据、修订和缺失日历返回可操作的修复说明。输入改变后，旧预览无法提交。同一提交的重试只产生一个任务。
- 真实验收目标为一个经用户授权的数据连接，记录可用时间、覆盖率、错误与数据模式。没有授权数据时保留外部验收待补状态。

## 阶段 30 · 多候选因子研究与审核

**交付**　从问题和反证生成一组受控 DSL 候选。复用既有候选上限、试验家族登记、评分、Holm 校正与一次性测试。工作台显示候选来源、公式去重、失败原因、预算、冻结和入库审核。

**验收**

- 用至少 10 个冻结问题覆盖十个因子家族。其中至少 6 个通过同一个入口完成多候选登记、验证、排序、冻结、测试与审核。
- 用同义表达、非法 DSL、重复候选、缺数据和中途取消验证控制。最终测试读取前，候选、方向、费用、参数和冻结证据均可复核。
- 将合法但证伪的候选、缺数据与执行失败留在完整分母。入库只记录明确审批的公式、市场、资产范围、时间域与用途。

## 阶段 31 · 策略样本外、组合与风险归因

**交付**　为现有模板增加滚动样本外、成本与流动性敏感性、参数稳定区间。支持有界的权重求解，显示行业和因子暴露、风险贡献、场景压力，以及毛收益到净收益的费用归因。优先复用已有本地计算与账本。

**验收**

- 选至少 6 个现有模板，覆盖股票、ETF、混合组合、事件和理论研究。每个适用模板走至少 3 个预先冻结的时间窗，分别标记可成交模拟、理论结果或缺数据。
- 用独立小样例核对权重约束、费用、现金和持仓，验证归因总额与净收益对账。极端流动性和不可行约束返回可解释状态。
- 先固定容量、成本、滑点与评价口径，再看样本外。一次参数变更产生新研究版本，报告可追溯到原账本和策略输入。

## 阶段 32 · 纸面策略结算与学习闭环

**交付**　把策略账本的已结算成交、可比基准和成熟观察窗接入现有学习服务。让用户审阅因子权重或风险规则建议，形成独立政策版本，并用冻结基线成对复跑。

**验收**

- 至少 3 条股票、ETF、混合策略路径完成「发布报告 → 观察 → 结算 → 提案 → 审核 → 成对复跑」。同时覆盖批准、拒绝、数据不足三种结果。
- 迟到价格、未结算交易、停牌、样本不足和重复来源保留明确状态。相同经济样本只计一次。原报告、原政策和已冻结队列可重复读取。
- 审核前后的政策指纹与复跑结果可逐项比较。批准后的配置携带范围与生效时间，重试与重启不会重复应用。

## 阶段 33 · 研究证据跨工作区复现

**交付**　扩展便携包，携带经过选择的时点面板、附件、版本化公式、策略与来源引用、冻结测试收据和学习政策。提供逐产物覆盖、可用版本和差异说明。

**验收**

- 在干净工作区复跑 4 条代表路径，覆盖普通研究、因子测试、策略账本和学习成对复跑。比较关键产物摘要与声明的数值容差。
- 校验损坏或缺依赖包、旧格式、版本变更、撤回来源和备份恢复。历史报告字节及审核记录通过恢复复核。
- 导出前由用户选择数据范围。凭证、接口地址和未公开样本外数据留在各自原有边界内。外部模型文本保留原证据与调用记录。

## 阶段 34 · 模型与 Codex 接入工作台

**交付**　将现有角色配置、模型材料预览、显式授权、调用记录和 Codex 交接集中到研究入口。评估一个可选的 Codex 执行器，在现有队列中处理类型化研究任务和可回传结果，复用本地工具许可与预算。

**验收**

- 使用受控接口覆盖 OpenAI-compatible、DeepSeek 与 Codex 交接的正常、超时、取消、迟到、回传冲突及重启路径。角色模型映射与证据分别可查。
- 未授权或证据不足时显示具体状态。预算与重试生效，报告能区分已发送、未知用量、未调用。冻结输入变更使旧结果无法写回新任务。
- 真实账户目标为两种兼容配置各跑一次授权的标准任务，外加一次真实 Codex 回传。测试证据须明确区分协议成功与研究语义检查。外部账户验收依赖用户自己的配置与授权。

## 阶段 35 · 试用、升级与可安装发布

**交付**　用真实试用梳理从安装到首份报告的路径，补齐失败恢复、版本升级、数据备份和可操作文档。把安装、浏览器、性能及 CI 证据与 GitHub Release 对齐。

**验收**

- 支持环境至少完成 macOS 与 Linux 的干净安装、旧工作区升级与备份恢复。离线合成首跑和用户数据首跑分别留证。
- 至少 5 名授权试用者记录首份报告的完成情况和阻断原因。目标至少 4 人无需维护者手工改数据或代码即可完成，保留样本规模与失败记录。
- 固定桌面和移动视口，检查键盘、加载、失败、空状态、离线报告及 10,000 项检索基准。发布时附安装包、源码包、校验和与已验证的安装步骤。
