# 量化实验与稳健性验证

## 从一项明确的问题开始

在“因子实验”选择已冻结的用户快照，也可显式生成标为 `SAMPLE` 的 240 条示例数据。填写问题，选择受控配方，声明窗口、标签跨度、验证折数、隔离间隔、成本及平台阈值，再提交后台计算。

研究顺序是：问题与章程 → 候选 → 训练/滚动验证 → 冻结 → 一次最终测试 → 验证排名与测试结果分列 → 显式研究审核。问题写入章程，候选只来自用户选定的配方和有界参数，不执行自然语言生成的任意代码。

计算通过现有独立 Supervisor/spawn、不可变快照、运行索引和报告收据发布。浏览器只显示服务器结果；重启后可从实验历史重新打开同一章程、测试占用和已校验报告。

实验最多接收 5000 条观察、8 个候选窗口和 4 个验证折。Manifest 写入、验证、收据读取与历史索引共用 8 MiB 上限；普通请求与收据仍使用原有较小读取限额。因子任务包含输入和全部报告的字节预算为 64 MiB、时间预算为 120 秒；超限保持明确失败，不登记为可用报告。

## 数据、时间与隔离

- 仅使用所选快照、标的和截止日内已知可用的数据；保持一 UTC 日期最多一条观察、下一观察执行前可用的历史边界。
- 默认固定 60% 训练、20% 验证、20% 最终测试。每个验证折只使用其之前的训练数据，训练窗口逐步扩展。
- 标签跨度和 embargo 都按观察数声明，不假定观察间隔就是一个交易日。标签结束越过阶段边界会被 purge；embargo 在下一留出区间前再隔开相应观察。
- 所有验证折都需要足够的训练和验证证据。缺字段、不可计算或样本不足的实验保留原因，但不排入成功候选。
- 测试前必须冻结候选和验证指纹。本地账本按标的及测试时间区间原子占用；重叠区间也会被阻断。换问题、成本、快照来源或应用重启不能重开同一区间。
- 验证阶段连同辅助基线、风险、配置和归因报告，都只使用最终测试期之前的观察。完整区间的辅助证据仅在冻结候选并取得原测试占用后发布，不能借基线报告提前查看留出期表现。
- 同一测试请求重发只取得原任务；失败或取消不释放占用。原任务在既定资源预算内的确定性恢复不是换选新候选。账本约束本地产品流程，不能证明用户此前没有看过原始数据。
- 章程声明、测试占用和入队之间若中断，重新打开历史会按原始持久化幂等键补齐或找回同一任务；不要求重新占用测试区间，也不创建替代候选。

这采用按时间向前验证的原则，但不直接依赖 scikit-learn，也不把不等间隔观察称为等时长折。[TimeSeriesSplit 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)特别区分了时间顺序、gap 和等间隔要求。

## 24 个研究配方

菜单包含 24 个不同公式：价格动量/回归、滚动均值与离散度、历史分位与缩尾、成交量特征、量价合成与背离、收益特征、滞后项、开/高/低价动量等。每项包含公式、字段、单位、实现版本、来源标识、PIT 语义及真实 DSL 数学复现。

这些是 Finathink 原创的 MIT 实现。参考了 [Qlib Alpha158 的特征分类](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)，未复制其代码；其 [MIT 许可](https://github.com/microsoft/qlib/blob/main/LICENSE)与用户数据许可是不同事项。用户数据的购买、权限与供应商 SDK 不由配方目录处理。

示例复现证明公式能够计算、历史结果不依赖未来输入，不证明市场有效或盈利。目录初始效果状态为 `NOT_EVALUATED_ON_USER_DATA`，实际效果由所选数据评估。旧 fixture 准入元数据不是这个研究菜单，也不构成生产因子入库证明。

## 排名、平台与多重检验

`ExperimentSummary` 统一保存快照、假设、参数、样本区间、分割、成本、指标、失败原因、版本及本次证据引用。

只有数据、实际可用日期、成本、分割和计算方法均匹配的结果才在同组比较。样本数量相同而日期不同也不视为可比。排名使用预先声明的绝对验证 Pearson IC，再按候选标识确定平局顺序；测试指标不参与换选或重排。

标的也是必需的可比条件：同一多标的快照中的不同股票不能因快照指纹和日期相同而归为一组。缺少标的或其他必要条件的旧结果保持 UNKNOWN。

平台必须满足提交时固定的指标底线、相邻指标差和最小连通点数。邻接只指声明网格上的一个轴步；缺点、失败点或对角点不能连接平台。有限指标、调用顺序和单个高点都不等于稳健，网格平台也不证明未测试的连续区间有效。

每个章程保留全部尝试和失败次数。探索性 p 值采用区块符号随机化，并对本章程所有尝试作 Bonferroni 校正；未知值不按零处理。该诊断依赖独立、符号对称区块假设，不证明数据满足假设，也不控制用户跨多个章程搜索的全局显著性。[多重检验方法说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)可用于核对校正术语；实现不引入 statsmodels 运行依赖。

## 成本、报告与审核

因子 IC、ICIR 和秩换手是描述性诊断。费用与滑点按章程固定；秩换手成本不是可交易组合的真实净收益。报告将固定策略基线和因子实验分开，不将两者混为同一种绩效。

“研究对比”展示全部已登记量化结果的条件分组及服务器计算的组内差异；这张快照不随下方元数据勾选改变。缺少明确条件的历史结果保持 `UNKNOWN`，不自动猜测可比。

最终测试的 `PASS` 表示留出证据可计算，不代表盈利。失败测试不能获准为研究提案；有效测试仍需用户显式记录审核。审核不自动写入生产因子库，不修改原报告或交易策略。

## 同一轮研究的风险、组合与执行

默认 `local-paper.v3` 只配置用户选择的一个标的，不自动买入快照里的其他资产。行业与停牌可通过通用 API 字段映射提供为 `industry`（稳定分类代码）和 `suspended`（严格布尔值）；与该条价格记录共用 `available_at`。缺行业保留 `UNKNOWN`，不从股票代码推断行业。新字段缺省时不会改写旧快照的内容指纹。

每个历史信号仅使用当时的已知前缀，依次应用单标的上限、现金底线、行业上限、信号暴露上限、历史 CVaR、市场/跳空/行业压力、流动性、停牌、价格跳变及回撤规则。报告列出每步约束前后权重和新增保留现金；该顺序是政策的一部分，不能解释成各约束独立的边际因果效应。

默认单标的上限 75%、现金底线 25%、已知行业上限 60%、未知行业上限 25%。行业只是用户声明的分类，不是经平台独立审核的分类。因子暴露定义为“仓位权重 × 已知两观察期动量收益”，不是通过 OHLCV 估计出的市场 beta 或外部风格因子。

CVaR 使用最多 60 条价格观察形成的收益，置信参数 95%，按经验分布的最差 5% 概率质量计算分数尾部均值，组合损失限额为 5%。尾部截点落在两个样本之间时按比例计入，不以浮点 `ceil` 取整。样本数和方法一起留档；少量观察的描述性损失不是统计可靠性或未来风险保证。

这里的暴露 CVaR 是“当前计划权重作用于历史标的收益”的尾部损失；历史绩效表的 CVaR 则来自已经回放的策略净收益序列，包含不同仓位路径与成本。两者口径不同，不要求数值相等。

固定压力假设为市场 -30%/组合损失上限 10%、跳空 -50%/上限 15%、行业 -20%/上限 10%，另检查信号反转暴露上限 5%。这些是显式政策场景，不是预测。配置复用既有确定性长仓分配器并验证可行性、换手和成本上限；不宣称数值优化或全局最优。输入缺少受约束因子、重复候选或约束不可行时保持阻断。

默认执行容量最多为观测成交量的 1%；成交量必须已标准化为可交易数量单位，价格与现金必须同币种。它只是容量模型，不代表真实可成交深度。历史回测在下一观察检查当条停牌与成交量，不能用未来成交量改变前一信号；不能成交时保留原持仓，部分成交如实计入数量、费用、滑点与权益。

最新纸面配置不是历史回测的最后一笔成交。它从该信号后延迟一条观察，仅使用截止点内已知归档价格；缺下一观察、数据尚不可用或停牌时，账本保留 `paper_pending`、零成交量与未花费现金。成交不足显示 `paper_partial`。报告分别展示计划权重、计划现金与执行状态，不把计划暴露说成已持有仓位。底层兼容 API 未声明延迟时仍支持归档即时模拟；产品默认路径始终明确指定延迟。

路径归因使用相同快照、观察区间和执行容量的三次确定性回放：原始策略零成本 → 原始策略含成本 → 前缀风控策略含成本。原始策略收益、成本差额和风险缩放差额加总到净收益，并显示残差与三份结果指纹；这是有顺序的反事实分解，成本差额包含成本改变持仓路径的后果，不等于简单费用加总，也不是唯一因果归因。

快照、运行、政策、暴露、压力、约束配置、纸面账本与归因共同保存到已校验 manifest 和离线 HTML；重启后读取同一份证据。仅比较政策、成本、样本与版本相同的结果。该固定基线与因子留出测试依旧分列，不将完整历史基线冒充未见过的 OOS 绩效。
