# Finathink 研究能力验收快照

日期：2026-10-27。范围是已确认的 Phase 10–15 计划；本记录区分实现、工程验证和外部验收，不将旧日期的诊断当作当前状态。

## 已接通的产品路径

| 环节 | 当前实现 | 证据与边界 |
| --- | --- | --- |
| 蓝白工作台 | 共用 AppShell、Overview、资料、研究、实验、复盘与设置 | 沿用指定 HTML；原有任务与安全合同保留 |
| 研究资料 | 12 个可发现方法、6 类公开行为档案、6 条反例 | 数量来自打包索引；可读不等于已加载或效果复现 |
| 方法路由 | 明确输入条件→选方法→完整有界上下文→持久化外部交接/类型化回传 | 用户显式操作，不自动调用当前 Codex 会话或执行模型代码 |
| 数据 | 通用用户 API、快照与独立字段附件 | 用户声明权限、单位和可用时间；不维护供应商 SDK |
| 可执行定义 | 5 个基础公式试点、5 类家族各一项定义 | 原式、版本、依赖、PIT 和方向明确；不是完整上游因子库或效果背书 |
| 验证 | 数据/语义/IC/去重/实际回测/OOS/增量/容量/归档九步 | 训练/验证/最终测试隔离；缺数据与执行错误不当金融证伪 |
| 范围治理 | 来源与本地证据分区；按公式/市场/股票池/时间域/用途/政策/评估审核 | 批准有明确范围；原批准与退出事件可追溯 |
| 研究观察 | 显式刷新独立窗口的描述性变化，形成既有审核通道中的研究注记 | 不自动调权或改风险规则；数据未满足时留在 OBSERVE |
| 纸面复盘 | 原结算→预览→显式审核→新配置→版本复跑 | 与因子验证观察分开；旧样本复跑标为回溯比较 |
| 报告 | 新生成蓝白单文件、同源图表/表格、方法/数据/政策/验证指纹 | 无实际账本不绘曲线；历史字节与创建时间保持不变 |
| 交付 | wheel 安装、独立 worker、重启、私密备份/恢复、浏览器 CI | 新资料与因子页面进入安装验收；外部付费调用独立验收 |

## 仍需单独取得的证据

- 用户真实数据 API 和付费模型的端到端验收：需要实际账户与逐次授权，当前工程样例不能替代。
- 上游实验效果、完整原始报告、数据许可和法律许可的独立审核：只认已有明确来源，不靠同名近似因子推断。
- 大型多资产生产样本、行业组合输入、市场冲击校准与真实成交结算：工程 fixture 与 paper-only 账本不代表这些验收。
- 当前部署边界是可信本地工作台，不扩张成敌对管理员或多租户隔离的承诺。

执行依据与裁定见各阶段计划、指南和 `docs/reviews/`。发布结果以精确提交的 GitHub 检查与合并记录为准。
