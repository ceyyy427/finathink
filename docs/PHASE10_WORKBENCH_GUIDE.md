# 蓝白研究工作台使用说明

工作台以用户提供的蓝白 HTML 为视觉基准，接入现有本地研究服务。问题、数据、计算与报告保持原来的运行关系，界面不会用合成收益或模拟倒计时替代真实任务。

## 从首页开始

1. 在“你想验证什么”中填写问题，点击“建立研究”。
2. 页面进入研究任务表单，保留刚才的问题；此时尚未提交任务、生成快照或调用模型。
3. 选择已有快照，或先在数据接口页面保存自己的 API 配置，再显式获取快照。演示数据需要单独选择，保持 SAMPLE 标记。
4. 核对标的、截止日、预算与执行配置，再点击任务提交按钮。需要模型分析时按所选配置明确授权。
5. 在运行记录中查看阶段、结果和报告，或进入因子实验、研究对比与复盘页面。

首页通过 GET 参数带入最多 1000 字的问题；超长参数会显示截取提示，正式提交前可在表单中核对和修改。参数仅用于预填，不被解释成程序或指令。

## 首页数字和图表

- 事件样例：明确标记的本地学习材料，不是实时市场事件计数。
- 已保存条目：个人本地工作区实际保存的节点。
- 学习证据：已保存的自查记录，不根据浏览行为推断。
- 研究运行：持久化研究索引中的运行记录。
- 活动图：按日期统计的实际记录条数，不是净值曲线或收益排名；下方表格保留相同日期的数据。

没有记录时显示空状态。更新失败时保留服务器渲染的可读内容，显示安全中文提示和重新载入入口。

## 导航与键盘

左侧保留研究、学习和系统入口；较少使用的页面放在“更多研究工具”，对应页面打开时仍有当前项标记。

“搜索功能入口”只搜索本地导航，不读取私人研究正文、不发起联网检索或模型调用。可用 Command K 或 Control K 打开，Escape 关闭并恢复焦点。

移动宽度下，菜单按钮打开导航。焦点进入导航，Escape 或关闭按钮返回原菜单；切换到桌面宽度会解除遮罩和 inert 状态。没有 JavaScript 时导航仍在文档内可用，首页问题仍能进入 GET 预填表单；提交和跟踪后台任务继续需要 JavaScript。

## 当前范围

本阶段统一 AppShell、总览和现有工作区样式，不重新构建研究引擎，不把 Codex 标记成自动连接。右侧研究路径是操作说明，不是虚构运行进度。

技能方法库、按需加载、来源因子与新报告模板按 Phase 11–15 接入。本阶段不重写历史离线报告。来源与本地结果继续分开，模型授权、研究审核和 paper-only 边界不变。

## 验证范围
