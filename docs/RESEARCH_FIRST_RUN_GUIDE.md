# 从自己的数据到第一份研究报告

打开工作台的“研究任务”，按顶部的四步提示操作。

## 1. 准备数据

在“数据接口”保存自己的 API 地址、认证和字段映射。保存配置不会读取数据。日频基线需要 instrument、timestamp、open、high、low、close、volume；available_at 用于判断当时能否获得数据。可补充行业 industry 和布尔停牌状态 suspended。

返回研究任务页，选择连接、标的、开始/结束日期及截止日，再声明价格币种和已换算的成交量单位。点击“获取并保存快照”才读取接口。单位声明随快照固定；界面不进行汇率、手数或合约乘数转换。未确认时保留“尚未确认”。字段不全时页面会列出缺少的字段。

也可以展开“使用明确标记的演示数据”，生成 SAMPLE 快照体验流程。SAMPLE 始终保留演示标记。

## 2. 检查本轮输入

选择快照、标的、研究截止日和问题，点击“检查当前输入”。检查只读取已保存的本地输入，不取外部数据、不调用模型、不创建任务。

- **需修复**：不满足当前流程条件，例如少于四条观测、同一 UTC 日期重复、快照损坏、数据可用时间未知或晚于执行边界、模型未授权。点击“核对并修复”定位相应表单；外部设置页在新标签打开，原输入保留。
- **待核对**：可做固定纸面研究，但解释受到限制，例如单位/停牌/行业声明未知或分析师材料不足。
- **已核对**：当前输入检查通过的项目，展开查看具体依据。

修改输入会让旧检查失效。“提交研究任务”也会先检查当前值；遇到阻断项时不会排队。

本地确定性流程无需模型 Key。研究模板只帮助组织问题，不改变基线算法。材料分析需要已配置的模型、符合时间与标的约束的材料，以及本次明确授权；保存模型配置本身不产生调用。

## 3. 跟踪任务

排队、运行、重试等待、取消、超时分别显示。展开“为什么这样运行”查看各阶段的输入、用途和已记录事实。阶段标记表示工作流到达过该位置，具体结果需检查对应证据。

刷新页面、重新读取记录或重启后，从同一个任务链接继续查看。此操作不会创建新研究。取消保留已有记录。

“沿用基础输入”只填回快照、标的、日期、问题和预算；原任务保持不变。材料需重新补充和核对，模型授权会取消，再次提交才创建新任务。在线失败后不会自动重试付费调用。

## 4. 阅读结果

先阅读结论、依据、分歧、适用条件和下一步。每个证据链接指向本轮报告的对应位置。没有记录模型分歧，不能理解为各方一致；未记录指标保持未知，零值仍显示为零。

技术指标、完整限制、模型调用记录和阶段码可展开查看。打开完整 HTML 报告后可保存离线阅读；新报告有同样的摘要，已保存的旧报告不会被本轮升级重写。

## 接口

`POST /api/research/readiness` 使用现有本地 CSRF 校验，接收研究输入（无需幂等键），返回 `research-readiness.v1`。响应含状态、`can_submit`、覆盖范围、输入摘要指纹和有修复入口的检查项。`can_submit` 表示固定纸面流程可以开始，不是投资适用性评级。获取快照接口额外接受 `price_currency` 与 `volume_unit`；声明通过后固定在快照中。

任务 API 增加 `research-explanation.v1` 解释、可用 checkpoint 标记和重试时间，复用现有任务状态。真实账户和服务质量验收继续按后续 Phase 18 独立进行。
