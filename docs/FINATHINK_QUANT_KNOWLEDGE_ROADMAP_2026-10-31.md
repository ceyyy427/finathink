# Finathink 量化知识库与研究能力扩展规划书

**范围：Phase 21–28。状态：Phase21已发布，Phase22实现、完整验收和独立审查通过（发布见PR #23），Phase23–28待实施。规划基线：已发布的Phase20。**

目标是把 Finathink 从“有可靠研究流程、内容数量有限”，扩展成“有系统知识、丰富因子与策略、可验证研究案例的量化工作台”。QUANTAXIS 和 DeepSeek HARNESS Quant 是重点学习对象；优先检查开源实现，再决定适配方法。既学习 UI，也学习数据结构、公式、评估、策略、风控、编排、失败经验与报告。

本轮已下载7个项目，记录2,886个跟踪文件，锁定62个重点材料文件的 SHA-256。已完成模块盘点和代表性源码审读；没有运行这些上游项目的全套引擎，也没有把其收益和性能声明当成本地实测。见[源码学习记录](research/2026-10-31-open-source-quant-study.md)和[来源锁定清单](research/2026-10-31-open-source-quant-lock.json)。

## 二、知识库应当是什么

每条知识都能回答：**是什么 → 何时适用 → 需要什么数据 → 如何计算 → 怎样被证伪 → 哪些研究使用过它**。

内容分六种：概念、方法、因子、策略、风险规则、研究案例。一个条目至少包含规范ID、中文解释、适用条件、公式/代码链接、输入字段、来源版本、反例、证据状态和相关研究入口。来源文档、整理后的知识、真实运行证据及用户私有笔记分开；它们通过引用关联。

  C --> E[因子与策略候选]

知识库优先做可验证的全文检索、知识图谱关联和研究入口；向量检索以后用同一题集评测，再决定是否加入。下载数量、文本长度和生成报告篇数不作为研究质量指标。

### Phase 21：先把“要学什么、有什么证据”变成资产

逐项检查 DeepSeek 的13类引擎组件、7类风险、因子维度、数据/入池/动态流程、Skill和UI；QUANTAXIS逐项检查实际目录。对动态注册、外部因子目录、文档存在但实现未找到的项目单独列缺口。旧目录中的8个未解析原定义逐个补证据或保持明确待补状态。

验收不会把“README写了123+”当作123项可执行能力，也不会把 QUANTAXIS README 的加速倍数直接写进我们的性能报告。下载文件不执行；组件适配时另做安装、调用和数据边界验证。

### Phase 22：先让人能学、能找、能带着依据研究

首批主题包含数据/PIT、收益与市场、统计推断、技术与价量、财务基本面、因子检验、策略与组合、风险与复盘。每个知识条目提供“入门解释—公式—代码/例子—应用—反例”分层阅读。检索结果显示来源和证据状态，并能带着明确依赖进入研究准备页。

检索评测先冻结问题和人工可核对的答案来源；搜索结果漂亮或模型语言流畅不算命中。用户笔记、掌握度与自己的研究结果保持私有，不混进公共内容包。

### Phase 23：补齐真正开展研究所需的底层表达

九类输入合同为行情量价、交易日历/股票池、复权与公司行为、财务公告/修订、行业/风格分类、机构汇总行为、事件/新闻、ETF净值/持仓、宏观/政策发布。字段由用户接口提供，平台负责时间、单位、版本与缺失诊断。

24个算子包括16个时序操作（滞后、收益、差分、和、均值、标准差、极值、秩、相关、协方差、斜率、线性衰减、极值位置、标准分）与8个截面/组内操作（排名、标准化、缩尾、去均值、中性化及组内变体）。截面排名和单资产历史排名必须明确区分。第一版保持低频股票/ETF研究；其他市场知识可入库，执行适配需单独合同。

### Phase 24：覆盖十类因子，而不只是增加技术指标名字

十类为趋势/动量、反转、波动/尾部、流动性/换手、价值、质量/盈利/应计、成长/投资、行业/风格、事件/机构行为、ETF/宏观状态。方向属于研究假设或经审核的范围结论，不能全市场永久写死。

来源因子卡>=120与可执行公式>=80分别验收；资料缺失的来源卡可以显示待补，但不能计入可执行数量。80个公式均有字段、窗口、单位、PIT、来源、可复现例子及失效场景；参数网格另计实验，不计新公式。

### Phase 25：让结果能解释、能反驳、能与独立实现对照

评分卡至少覆盖IC/ICIR、分层收益与单调性、换手、衰减、行业/市值分组、时段稳定性、成本/容量、相关性家族与增量贡献。训练/验证/最终测试严格隔离；扩展试验次数、选择偏差和多重检验记录。

固定受控样例使用64标的×756观察日，并准备停牌、退市、极端收益、晚公告、覆盖缺口等变体。合成结果仅证明工程行为；有真实用户数据时另生成按市场/区间/数据许可限定的研究记录。反例失败算研究产物，坏数据或执行错误不算金融证伪。

### Phase 26：从因子进一步成为完整策略研究

首批12模板：等权基准、单因子分层、短期反转、趋势突破、低波/低换手防御、价值质量、多因子中性、ETF风险预算、ETF相对强弱轮动、市场状态调仓、公告/事件研究、配对均值回归。每个模板配置输入、股票池、权重、调仓、成交与成本、风险、基准、边界。

至少12类风险规则覆盖数据/PIT、财务异常、可交易性、流动性、集中度、行业暴露、因子共线、波动预算、尾部风险、止损/逻辑失效、回撤、压力情景。缺财务字段不能推断“低风险”；异常评分不能宣称欺诈事实。参考上游的规则结构，参数依数据和审核版本固定。

借鉴五池思想，按自动扫描、量化基线、用户、模型、公开行为方法记录决策来源；另以观察/候选/决策表示研究进度。按同一经济信号去重，跟踪1/5/20/60观察间隔，确保不同来源的比较使用可比输入。

### Phase 27：补上从问题到因子候选之间的步骤

完整路径为：问题澄清/用户风格→知识检索与反例→可证伪假设→数据合同与覆盖检查→预注册验证设计→生成受控公式/策略→重复与家族检查→训练验证→冻结测试→分析师综合→审核→纸面观察→知识回写建议。

基本面、技术、情绪、新闻、学习分析师并行读取各自需要的知识和证据，经理保留分歧与不确定性；风险和组合工作继续使用已有运行时。模型供应商与API授权沿用现有合同，不复制上游 DeepSeek 专属凭据机制。一次研究最多24个假设，默认2个研究任务并发，成本/轮次耗尽后保留检查点。

### Phase 28：把内容、工具和证据放到一个好用的工作台

入口包含知识地图、因子研究、策略研究、风险工作区、研究池、实验比较和学习建议。优先呈现可研究的问题与“需要哪些数据”；详情展示来源、实现、验证、批准四种不同状态。决策卡、研究库、因子卡和历史比较借鉴 DeepSeek 的组织方式，整体继续采用当前蓝白布局与交互规范。

上游更新只生成差异和待审内容，旧版本继续复现。安装包、离线单文件报告、备份恢复都包含新内容及来源引用；不依赖从开发者电脑的参考目录读取文件。

## 五、每阶段统一验收规则

1. **内容完整**：数量来自机器可读清单、按规范ID去重；源文件与许可证可定位；目标范围的每个条目有明确状态。
2. **算法可核对**：手算/独立实现对照、单位、缺失、极值、时点、跨资产隔离；不能用与实现同构的测试宣称正确。
3. **流程可运行**：真实本地HTTP→现有worker→持久产物→报告；验证取消、重启、幂等、错误及迟到响应。
4. **证据不越级**：未运行显示未运行，缺数据显示缺数据；来源业绩不冒充我们的回测；同源信号不重复投票。
5. **交付可安装**：前端构建、已有回归、独立审查、全新wheel和备份恢复；最终PR与main的CI都通过。

详见[共同设计与合同](superpowers/specs/2026-10-31-finathink-quant-knowledge-expansion-design.md)。内容覆盖目标与使用指南随每阶段实际验收更新，不能提前改成“已完成”。
