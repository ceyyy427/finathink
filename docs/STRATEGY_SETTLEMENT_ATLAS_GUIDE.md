# 从研究图册到纸面策略复盘

安装发布页的 Python 安装包后，运行 `finathink --offline`，在浏览器打开 `http://127.0.0.1:8765/`。第一次使用可以直接打开内置动量实验和纸面账本示例。

总览的地形图把「数据」「因子」「验证」连接到对应工具。顶部可切换四个研究视图，右侧的工具目录和搜索可打开现有工作台。

| 入口 | 可以核对的内容 |
| --- | --- |
| 证据 | 选择快照、标的和图上的字段，比较观测时间与可用时间，查看原始记录。 |
| 因子实验 | 用同一条价格序列计算两个窗口的动量。先查看开发区间，再显式提交带成本设置的实验。正式验证结果在原有因子研究工作流中保存。 |
| 研究记录 | 读取归档报告。在纸面账本上逐期比较策略和基准，或打开明确标注的内置示例。改变日期用方向键，整段净值可展开为表格。 |

## 完成一次结算与审核

1. 打开「策略与纸面账本」，选择模板、数据和参数并提交。第一次体验可用「等权组合」和固定股票与 ETF 合成样例。发布完成后从总览的「最近研究」打开报告。
2. 在「运行复盘」核对账本，再选「观察与结算」。选定观察截止日后读取已结算窗口。也可从「复盘与学习」的「策略账本结算与学习」进入。
3. 展开窗口记录，核对实际成交、费用后收益、同日期的基准收益、样本身份和排除理由。每窗固定五个观察间隔。迟到价格、未交收、停牌、无成交或缺少可比基准会留下具体状态。
4. 选择「审核结算样本」。至少需要三个互不重叠的合格窗口。当平均超额收益低于零且超过半数窗口落后基准时，可以提出一次纸面敞口试验。提案会列出父政策、参数变化和作用范围。重复报告或重试会保留原经济样本身份。
5. 填写审核依据，选择批准或拒绝。批准创建带生效时间和指纹的新政策版本。本轮规则将信号预算乘以 0.8，最低为 0.1。拒绝记录保留在原提案上。
6. 选「用原冻结策略成对复跑」。左、右两侧独立执行同一模板、数据和费用设置。基线结果逐项核对原报告，再比较已批准政策的成交、费用、净值与共同基准。「打开运行审阅曲线」可浏览逐期差异和导出原始 HTML 报告。

成对复跑重用已知的历史窗口，结论属于回溯比较。对生效后的同范围策略，用户可以显式应用此版本并保存执行证据。模板、标的、市场、成本、基准或日期不匹配时，界面会给出原因。样例、纸面执行和用户保存的快照分别保留来源。

## 复核记录

策略报告、冻结面板、可比基准、观察收据、审核决定和成对复跑各有独立指纹。重启后可从「已保存的策略观察」找回原记录。复盘曲线和逐期表取自同一份数据；策略缺少同日期的完整基准时，相对指标显示为空。已有 HTML 报告仍可按原始字节导出。
