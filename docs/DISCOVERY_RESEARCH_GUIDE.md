# 自然语言研究计划

从中文研究问题开始。可以问「挖掘均值回归因子」或「等权组合的集中风险如何」。系统检索知识、反例和版本化方法，将清楚的问题收敛到一个受控因子定义或策略模板。无法唯一识别主题时，缩小问题范围再预览。研究风格可以选平衡、防御或低换手，用于调整复核重点。

## 预览和执行

1. 用本地应用的会话凭证向 `POST /api/research/discovery/preview` 提交 `question`、`profile`，以及可选的 `contract` 和 `attachment_refs`。预览给出数据状态、反证条件、分割设计、风险政策和版本指纹。
2. 出现 `NEEDS_DATA` 时，前往数据页面补充真实字段与时点附件，再预览。出现 `NEEDS_CLARIFICATION` 时，聚焦单个主题。出现 `BUDGET_STOPPED` 时，重新选择上下文预算。
3. 就绪后向 `POST /api/research/discovery` 提交同一组输入、`blueprint_fingerprint`、`authorized: true` 和 `idempotency_key`。提交返回后台任务；因子路径也返回实验 ID。
4. 在因子实验页查看验证结果。用户显式冻结候选后才可运行一次样本外测试，随后可以记录研究用途审核。策略报告使用既有纸面账本，用户可以把经复核的策略决策放入研究池并观察。
5. 在离线报告中展开五位分析师的证据，检查各自的数据缺口、反例和引用。知识建议关联已发布研究产物，等待进一步审核。

选择已有模型配置的策略研究还需明确提交 `allow_model_calls: true`，材料通过已有授权和可用时点校验。模型意见和分歧随报告保存，数值由本地引擎计算。因子预注册和冻结测试使用离线分析。已完成的本地研究可通过对应的外部交接接口导出冻结方法，因子需等样本外测试完成；回传前重新核对输入、方法和政策。

固定回归问题与验收证据见[阶段 27 审查记录](reviews/2026-10-31-finathink-phase27-review.md)。
