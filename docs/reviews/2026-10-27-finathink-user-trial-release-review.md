# Phase 9 中文交付质量：实现与验收记录

基线：`be081d004522901f27cd2078d1d9aeb7a677701a`。范围为产品完成路线 Task 9，以及用户明确要求的异常响应中文提示优化。

## 实现结果

- 共用安全中文请求处理：不完整响应、JSON 解析、网络异常和 HTTP 错误有恢复办法；保留安全的中文校验，不直接显示 JavaScript 诊断、私密路径或响应细节。原表单与提交幂等标识保留。
- 中文导航、数据接口表单、首次使用步骤、研究问题模板、数据/模型准备状态、服务器耗时与预算，以及每页 20 项历史。
- 原生表单正向旅程修复：`no-referrer` 导致 Chromium POST 的 Origin 为 `null`，现使用 `same-origin`，继续拒绝 null/cross-origin；Bearer/no-auth 表单不提交 header 模式字段，JSON API 校验规则不放宽。
- 已完成任务的报告若丢失/损坏，仍保留历史完成事实，但关闭报告链接与指标并显示恢复提示。
- 诊断导出包含有界研究摘要，不读取 Keychain/环境变量值，不含私人文件名、路径、问题、数据行或端点。新 POSIX 状态目录与主库分别使用 0700/0600，不更改既有用户目录权限。
- 新维护 CLI 只备份指定主库、相邻引用配置和 artifacts，关闭应用后使用；恢复至新目录，校验清单、摘要和 SQLite，不覆盖原始数据。链接、活动任务、保留配置名、同名输出和损坏包失败闭合。
- 新安装 runner 从独立虚拟环境的 wheel 导入，通过真实 HTTP 与 Supervisor/spawn 生成报告，实际使用已安装维护入口备份/恢复，再重复启动校验历史与迁移。

## UI 与性能

沿用批准的深色 AppShell，不引入第二套组件或前端框架。Impeccable harden 用于中文异常、空状态、弱设备和文本可读性；机械扫描的 8 个 side-tab 警告均来自未更改的既有 CSS，按当前视觉边界保留，不借本轮重设计。

首轮截图和布局测量后，仅将新增首次使用向导从继承的 15px 调至 16px，并用浏览器断言确认。1440×900、1920×1080 与 375×812 无横向溢出；键盘启动、翻页、可见焦点与 ARIA 树有证据。

本机 Chromium `149.0.7827.55`。25 项任务的 4 倍 CPU 限速翻页旅程实测约 0.6 秒，每页最多 20 项 DOM；10,000 行图表解析本轮约 13 ms。每次 CI 保留自己的实际数据，不将本机单次值视为性能保证。
