# 因子检验与稳健性研究

因子检验工作区围绕预先登记的问题、固定数据和验证设计生成评分卡。每次研究保留所有候选的结果、失败原因、数据范围和版本。来源定义与用户样本上的研究证据分别留档。

## 使用流程

1. 从因子定义库选择要检验的公式，阅读字段、观察频率、单位和适配说明。
2. 登记候选、试验家族、时间切分和成本假设。一个批次最多24项，应用继续使用已有后台队列和并发上限。
3. 显式提交研究，查看每项评分卡与数据诊断。缺字段或计算失败保留在试验记录中。
4. 根据验证集选择候选并冻结，之后才读取最终测试区间。已消费的测试区间保留登记。
5. 阅读离线报告中的反证、独立对照、局限与下一步建议；用途审核沿已有流程进行。

## 如何读评分卡

| 项目 | 回答的问题 | 阅读要点 |
| --- | --- | --- |
| IC / ICIR | 因子与后续收益是否有关联 | 区分截面与时间序列；查看有效样本、并列值与方差不足 |
| 分层收益与单调性 | 信号从低到高是否呈有序差异 | 查看持仓滞后、可交易性、层内覆盖与成本 |
| 换手和成本 | 信号变化付出了多少交易代价 | 保留单边换手定义、双边费用及bps换算 |
| 衰减 | 关联随持有间隔如何变化 | 远期标签必须完整落在当前验证区间内 |
| 行业、规模与时段稳定性 | 结果是否集中在某些分组或区间 | 小组样本不足需要保留诊断 |
| 容量 | 交易规模相对成交数据是否合理 | 成交额和可交易数据必须与研究口径一致 |
| 相关性与增量 | 新信号是否提供已有信号之外的信息 | 拟合只使用训练区间，来源别名不增加独立样本 |
| 多重检验 | 尝试很多候选是否增加误选风险 | 所有预登记尝试，包括失败与未知项，属于声明的检验家族 |

指标来自明示的数据和计算方法。诊断型分层收益与实际纸面成交账本各自保留口径；评分卡同时提供样本数、覆盖情况和不适用原因。

## 研究结果与证据

`PASS`、`FALSIFIED`、`NEEDS_DATA`、`EXECUTION_FAILED`分别表示通过预登记的研究条件、在适用输入上被反驳、缺数据、执行失败。判断都带有样本、窗口、成本和方法范围。

合成SAMPLE的结果标记为工程复现。用户数据研究必须绑定自己的数据指纹和来源口径；学习审核仍核对真实结算、可用时间、证据摘要及反证完整性。缺失或损坏的反证会保留阻断原因。

## 可复现样例与独立对照

本阶段提供固定种子的64标的×756观察点样例。生成规范、输入摘要、切分和边界变体可被重跑；执行分片保持完整同日截面与足够历史窗口。独立对照在隔离环境读取固定版本Alphalens，应用运行环境继续使用既有依赖。

反例库记录输入、实际结果、修正和适用边界，涵盖时点、样本覆盖、成本、重复试验与执行异常。反例也是研究产物，能够帮助解释信号为什么失效。
