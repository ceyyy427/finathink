# 策略验证室

验证室回答两个问题。第一，一条已经发布的策略在后续历史区间的表现如何，费用和可成交量改变后是否还能成交？第二，原账本最终赚亏了多少，各项交易成本与持仓怎样解释这个结果？

## 从一份账本开始

1. 在侧栏打开「策略验证室」，也可以从「运行复盘」的一份已发布策略进入「验证样本外表现」。第一次使用时点击「生成纸面示例账本」，后台会用固定的股票和 ETF 合成数据生成等权策略。使用自己的数据时，在「策略与纸面账本」选择已保存的面板并发布策略。
2. 选择来源账本，填写训练期数与测试期数。展开参数设置可以指定候选值、稳定容差、费用基点、滑点基点、成交量参与上限、组合目标仓位与单一标的上限。页面中的比例采用小数，例如 0.4 代表 40%，10 个基点代表 0.1%。
3. 预览三个测试区间、各自训练区间和压力假设。预览保存冻结方案，提交后才开始计算。重试同一方案会打开同一任务，改变窗口、成本或权重约束会生成新的方案指纹。
4. 在「验证记录」或后台任务页回看结果。「打开验证报告」提供独立的 HTML，可保存到本地离线阅读。报告记录数据模式、原报告、账本、面板及策略政策的引用。

## 怎样读一扇窗口

默认取最近 80 个可用观测，使用 32 个训练观测和随后 16 个测试观测，向前滚动三次。相邻训练范围可以重叠，三个测试范围按时间排序且互不重叠。数据不足时，每扇窗口保留实际覆盖和原因。观测频率由用户面板决定。

每扇窗口只按训练数据选取候选。常规多头模板以训练净收益率评分，理论价差和事件模板以各自的成熟观测统计评分。并列时先选接近原策略参数的值，再取较小值。稳定区间记录哪些相邻候选落在预先设置的得分容差内。

样本外测试重新从冻结的现金与空仓开始。训练历史只用于指标预热，纸面订单在后续观测执行。基准与三个单项压力回放共用初始账户、测试日期及入选参数；费用、滑点、容量分别变化。费用和滑点压力分别取基准的两倍或增加 5 个基点中的较大值，最高 100 个基点。若基准已经达到上限，该项压力使用相同费率。容量压力使用基准参与上限的十分之一；零容量按无法执行处理。三个窗口各有独立账户，适合逐窗对照。曲线下方的数据表可以核对具体日期和数值。

| 窗口结果 | 可以读取的证据 |
| --- | --- |
| 纸面模拟 | 测试期成交、净值、费用、滑点及同区间基准；主动持有现金时也保留测得的现金收益 |
| 理论研究 | 成熟事件的价格变化，或按延后一期开仓计算的理论价差 |
| 无法成交 | 当时的容量、风控门槛和订单原因 |
| 数据不足 | 缺少观测、有效信号、可用政策或估值输入的位置 |

价格与规则记录完整时，训练期允许指标积累所需的历史观测。缺失的净值、市场状态或流动性字段会使该候选缺少训练得分，即使后续已有成交。策略主动保持全现金时，账本记录零收益与同期基准。成交量参与上限设为零时，验证在执行前标记为「无法成交」。

## 怎样核对原账本

「原账本组合诊断」读取最初发布的持仓与现金。逐资产汇总参考价格损益和股息，得到毛损益，扣除实际费用与滑点后与期末减期初净资产对账。拆股、结算中的现金及可用现金均保留原账本口径。

行业分布和风格 Beta 使用收盘时可知的字段，同时列出有资料与缺资料的持仓权重。风险贡献按实际期末权重、最多 60 个对齐的拆股调整价格区间估计协方差。压力测试分别对股票、ETF 施加预定冲击，现金冲击为零。权重试算在目标仓位、单一资产上限和资格条件内，寻找最接近原权重的组合；约束不可行时显示原因。试算结果保存在本次研究中。

## 验收与复核

- 12 个模板使用同一引擎。合成样例涵盖股票、ETF、混合组合、事件统计和理论研究。测试固定训练边界，扰动测试期数据，验证训练选参维持原值，并覆盖零成交容量、缺证据和政策生效日期。
- 独立手算账本覆盖成交、拆股、股息、现金、持仓和费用。毛损益 15.20，费用 3.50，滑点 2.50，净损益 9.20。此数值是测试样例的对账结果。
- 浏览器路径覆盖样例生成、冻结、提交、后台回放与报告打开。服务回归覆盖并发重复提交、重启重读、工作区隔离及冻结方案完整性。安装测试从构建好的 wheel 重走验证路径。
