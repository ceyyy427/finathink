# 研究差异、迁移与量化证据

打开「研究对比」，选择两项已经生成报告的研究，再点击「比较研究条件」。工作台逐项展示数据与样本、方法与口径、参数、费用与滑点、风险政策、代码与依赖。条件完整且一致时显示右侧减左侧的基线指标差值；不同或缺失条件逐项说明原因。

## 迁移一项研究

1. 打开「研究对比」，选择左侧已发布研究。要复算学习对照，选择已有的普通或策略成对复跑。
2. 默认只导出元数据。勾选「在研究包中携带已发表的标准化数据」后，可以选择「标准化行情」或「研究工作流」。复算因子、策略和学习对照时选择「研究工作流」。文件可能包含所选资产的价格、成交量、字段修订、可用时间和纸面账本。
3. 在目标工作区选择导出的 JSON，点击「恢复研究包」，再点击「复算已恢复产物」。恢复和复算是两次独立操作，重启后可查看已经保存的包与回执。
4. 在回执中逐项查看哪些计算已复现、哪里出现差异、哪些材料仅归档，以及还缺少哪些数据、版本或来源许可。

首次试用可从 v0.2.6 发布附件下载 `finathink-phase33-examples.zip`。解压后，从 `packages/` 选择一项合成样本研究按第 3 步操作，然后与 `receipts/` 中的同名回执核对。压缩包内的 README 列出实际使用的 Python、NumPy、pandas 版本及校验命令。

| 选择的研究 | 本地重算和核对的证据 |
| --- | --- |
| 普通研究 | 基线回测与纸面风险、多资产量化证据 |
| 已发表的冻结因子测试 | 冻结候选、公式版本、测试范围及原测试结果；需要独立字段的公式使用同时导出的已发表附件 |
| 经方法交接的九步因子测试 | 使用已接受的 DSL 提案、带可用时点和单位的字段附件、原样本切分、手续费及滑点，逐步核对信息系数、纸面回测账本、样本外稳定性、增量与容量等九步结果 |
| 策略与策略验证室 | 风控决策、成交、账本和可比基准；验证室还按原方案重算滚动窗口和组合归因 |
| 普通学习对照 | 复核原观察与批准记录，在相同数据上执行基线和批准政策，比较两个子报告及指标差值 |
| 策略学习对照 | 由冻结账本重建已结算观察窗，核对批准的预算规则，分别执行两侧策略并比较净值、费用、成交与基准 |

每个工作流包最多 32 MiB，普通基线行情最多 5,000 条。九步测试要求验证和最终测试各有一份独立的原始发表回执。目标工作区核对冻结候选、完整面板、代码版本、方法与来源文件摘要，并检查来源是否撤回。外部提案生成过程只作归档，复算从原先接受的公式开始。在缺少 Git 修订号的 wheel 与源码工作区之间迁移时，必须与原发表记录逐项匹配源文件摘要、Python 和数值库版本、引擎与策略内核版本。两端已知的 Git 修订号不同时，九步复算会阻断。回执显示已检查的字段数量，原件里的整数、文本、版本及账本指纹精确核对，浮点使用绝对容差 `1e-10` 和相对容差 `1e-9`。回执先显示前 24 处差异。超过 24 处时，展开该产物并选择「查看全部差异」，每页可核对 100 项。

工作区只用本机支持的计算版本重放。代码或依赖变化、已撤回的公式或策略来源、缺少必要材料都会形成阻断。出现差异时可核对回执中的预期摘要、复算摘要与数值容差。内容摘要用于识别变更，来源许可与审核仍需由原始记录证明。

连接凭证、接口地址、私有提示材料和未公开的测试数据保留在源工作区。外部模型调用记录和文本保留原证据关系，目标端复算使用离线计算。便携包不会安装审批政策、领取新的测试机会或提交交易。可在「包内历史文件」读取清单，下载历史文件并核对 SHA-256。完整迁移工作区的运行状态和审批登记可使用私密备份恢复。

旧格式 `research-package.v1` 按原先的范围恢复和复算，可核对基线与量化证据。旧包声明依赖原工作流的产物继续显示该状态。要核对新增产物，从完整原报告重新选择工作流范围并导出。

## 阅读多资产证据

在研究任务页选择自己的数据连接，在标的栏填写 `AAA,ETF`，选择价格币种与成交量单位，再展开「多资产证据声明」填写 `{"AAA":"EQUITY","ETF":"ETF"}`。点击获取后，声明与快照一起冻结。价格与现金必须同币种，成交量已换算为股或份。

现有数据入口记录 `units.price_currency` 与 `units.volume_unit`；直接构造快照也可使用以下等价声明：

```json
{
  "units": {"price": "USD", "cash": "USD", "volume": "shares"},
  "asset_classes": {"AAA": "EQUITY", "ETF": "ETF"}
}
```

数值必须已经标准化为声明单位；这些是用户声明，不代表平台核验过数据供应商。计算允许 2–20 个资产、最多 20000 条观测，只聚合同币种输入。

每个资产先计算自己的相邻观测收益，再按完全相同的起止时间取交集。缺口不填零、不前向填充；数据需要在历史执行边界可用，暴露使用共同截止点当时可用的信息。页面同时展示：

- 样本、共同区间覆盖、固定等权研究权重、行业与两期动量暴露。
- 样本协方差 Euler 方差贡献：`w_i × (Σw)_i`，贡献可为负，总和等于组合方差。零方差时不显示贡献百分比。
- 95% 经验 CVaR、市场/行业/动量压力情景与各资产损失归因。
- 市场冲击 −10%、−20%、−30% 的敏感度及未超过 15% 声明损失上限的已测点。
- 共同收益均值的 95% 移动区块 bootstrap 区间：固定种子 19、200 次、区块长度 `ceil(sqrt(n))`。至少 20 个连续且等长的共同区间才计算；样本不足或不连续时显示原因。移动区块不首尾拼接，端部观测会被较少抽到；固定区块与 200 次重采样未经真实市场覆盖率校准。

原因子实验的参数网格、稳定区域和阈值在同一证据区域展开阅读。这些口径是历史研究，不是实际决策持仓；等权收益未扣成本。置信区间不是未来盈利概率，稳定点不是未经测试的连续安全区间。SAMPLE/合成样例只用于计算验收，来源研究主张单独保留为未验证。

实现参考 [NumPy 样本协方差文档](https://numpy.org/doc/stable/reference/generated/numpy.cov.html) 与 [arch 区块重采样文档](https://arch.readthedocs.io/en/latest/bootstrap/timeseries-bootstraps.html)。本地实现复用已安装 numpy；没有引入 arch 依赖或复制其代码。

## 本地接口

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/api/research/reproduction` | 当前工作区已恢复包的摘要与回执 |
| GET | `/api/research/reproduction/compare?left=运行ID&right=运行ID` | 六类条件与双侧证据 |
| GET | `/api/research/reproduction/pairs` | 当前工作区学习成对复跑的标识、类型与状态 |
| POST | `/api/research/reproduction/export` | 普通研究选择 `run_id`；工作流选择 `run_id` 或 `pair_id`，同时提交 `data_scope="workflow"` 和 `include_data=true` |
| POST | `/api/research/reproduction/restore` | `package`：完整 JSON 对象 |
| GET | `/api/research/reproduction/包摘要` | 恢复状态 |
| GET | `/api/research/reproduction/包摘要/differences?product=产物名&page=0` | 已保存回执的逐项差异，可传 `receipt_id` 绑定到同一次复算 |
| GET | `/api/research/reproduction/包摘要/history` | 工作流包内的历史文件、内容和 SHA-256 |
| POST | `/api/research/reproduction/包摘要/recompute` | 显式本地复算 |

所有 POST 需要当前页面的 `_csrf`。GET 不启动研究、复算或模型调用。页面提供键盘操作、加载/错误/空状态和移动适配；未启用脚本时仍可阅读原研究库存和量化条件。

## 从安装包复核

在源码目录运行 `python scripts/clean_install.py` 会构建 wheel、创建独立虚拟环境并启动两个本地工作区。验收脚本通过 HTTP 分别迁移普通研究、冻结因子测试、策略账本、策略验证室、普通学习对照和策略学习对照，检查每项复算结果与归档报告的原始字节。最后从私密备份恢复原工作区，两次重启读取同一份报告和批准记录。
