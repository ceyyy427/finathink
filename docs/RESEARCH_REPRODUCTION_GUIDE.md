# 研究差异、迁移与量化证据

打开「研究对比」，选择两项已经生成报告的研究，再点击「比较研究条件」。工作台逐项展示数据与样本、方法与口径、参数、费用与滑点、风险政策、代码与依赖。条件完整且一致时显示右侧减左侧的基线指标差值；不同或缺失条件逐项说明原因。

## 迁移一项研究

1. 选择左侧研究，点击「导出左侧研究包」。默认包含冻结条件、数值产物和缺依赖清单。
2. 要在另一工作区复算，先勾选「携带已发表的标准化数据」再导出。包内会包含价格、成交量、历史可用时间、行业和用户声明的单位与资产类型。文件需要由用户决定如何保存和分享。
3. 在目标工作区选择 JSON 文件，点击「恢复研究包」。恢复只保存本地包，不调用模型，也不修改原研究或风险政策。
4. 点击「复算已恢复产物」。逐项查看基线回测与风险、多资产证据是否一致。研究包和回执在重启后继续可读。

「已覆盖产物一致」表示当前包声明的确定性数值与重新计算的值一致；「部分产物已复现」表示还存在需原研究流程恢复的产物；「复算产物存在差异」表示数值未通过匹配。缺少数据、代码内容或 Python / numpy / pandas 版本时，显示待补条件。每个工作区最多保留 20 个迁移包，每包最多 8 MiB、5000 条观测。

连接配置、API Key、端点、提示词、私人模型材料和原始来源文本不会进入研究包。脱敏数据有自己的摘要，并保留原数据摘要作为引用。复算核对数值，不把原数据出处、运行标识、生成时间或 HTML 字节当作相同。内容摘要提供一致性校验，不是第三方来源认证；恢复不会执行包内代码或自动下载依赖。

验证阶段只导出已发表的数据前缀。因子方法、独立字段附件和冻结测试授权继续走原因子研究流程，研究包列出这些依赖；模型文字需要原材料、模型配置与明确授权，不能由基线复算替代。旧报告缺少冻结执行身份时，应从原输入新建研究。

## 阅读多资产证据

在研究任务页选择自己的数据连接，在标的栏填写 `AAA,ETF`，选择价格币种与成交量单位，再展开「多资产证据声明」填写 `{"AAA":"EQUITY","ETF":"ETF"}`。点击获取后，声明与快照一起冻结。价格与现金必须同币种，成交量已换算为股或份。

现有数据入口记录 `units.price_currency` 与 `units.volume_unit`；直接构造快照也可使用以下等价声明：

```json
{
  "units": {"price": "USD", "cash": "USD", "volume": "shares"},
  "asset_classes": {"AAA": "EQUITY", "ETF": "ETF"}
}
```

数值必须已经标准化为声明单位；这些是用户声明，不代表平台核验过数据供应商。计算允许 2–20 个资产、最多 20000 条观测，只聚合同币种输入。

每个资产先计算自己的相邻观测收益，再按完全相同的起止时间取交集。缺口不填零、不前向填充；数据需要在历史执行边界可用，暴露使用共同截止点当时可用的信息。页面同时展示：

- 样本、共同区间覆盖、固定等权研究权重、行业与两期动量暴露。
- 样本协方差 Euler 方差贡献：`w_i × (Σw)_i`，贡献可为负，总和等于组合方差。零方差时不显示贡献百分比。
- 95% 经验 CVaR、市场/行业/动量压力情景与各资产损失归因。
- 市场冲击 −10%、−20%、−30% 的敏感度及未超过 15% 声明损失上限的已测点。
- 共同收益均值的 95% 移动区块 bootstrap 区间：固定种子 19、200 次、区块长度 `ceil(sqrt(n))`。至少 20 个连续且等长的共同区间才计算；样本不足或不连续时显示原因。移动区块不首尾拼接，端部观测会被较少抽到；固定区块与 200 次重采样未经真实市场覆盖率校准。

原因子实验的参数网格、稳定区域和阈值在同一证据区域展开阅读。这些口径是历史研究，不是实际决策持仓；等权收益未扣成本。置信区间不是未来盈利概率，稳定点不是未经测试的连续安全区间。SAMPLE/合成样例只用于计算验收，来源研究主张单独保留为未验证。

实现参考 [NumPy 样本协方差文档](https://numpy.org/doc/stable/reference/generated/numpy.cov.html) 与 [arch 区块重采样文档](https://arch.readthedocs.io/en/latest/bootstrap/timeseries-bootstraps.html)。本地实现复用已安装 numpy；没有引入 arch 依赖或复制其代码。

## 本地接口

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/api/research/reproduction` | 当前工作区已恢复包的摘要与回执 |
| GET | `/api/research/reproduction/compare?left=运行ID&right=运行ID` | 六类条件与双侧证据 |
| POST | `/api/research/reproduction/export` | `run_id`、可选布尔 `include_data` |
| POST | `/api/research/reproduction/restore` | `package`：完整 JSON 对象 |
| GET | `/api/research/reproduction/包摘要` | 恢复状态 |
| POST | `/api/research/reproduction/包摘要/recompute` | 显式本地复算 |

所有 POST 需要当前页面的 `_csrf`。GET 不启动研究、复算或模型调用。页面提供键盘操作、加载/错误/空状态和移动适配；未启用脚本时仍可阅读原研究库存和量化条件。
